인사말을 보여 주는 프로그램인데, 직원 전용 자료는 내부에서만 켜는 값이
있어야 보여야 해요. 그런데 누군가 평소보다 긴 이름을 입력했더니 직원 전용
자료가 나왔다는 제보를 받았어요. 저는 긴 이름을 몇 번 넣어 봤는데 재현하지
못했습니다. 프로그램 파일과 접속 주소를 드릴 테니, 실제로 이름 입력만으로
직원 전용 자료를 볼 수 있는지 확인해 주세요.
::

:person[문지기]는 작은 사무실의 방문자 접수대 프로그램을 관리한다. 이 프로그램은
방문자 이름을 입력받아 인사말을 보여주고, 내부에서만 설정하는 직원 여부 값이
켜져 있을 때만 직원 전용 자료를 보여준다. 평소에는 이름을 입력하는 것만으로
직원 여부가 바뀔 방법이 없다고 설명한다.

팀원 중 한 명이 평소보다 긴 이름을 입력했더니 직원 전용 자료가 나왔다는
제보를 전달했다. 문지기는 짧거나 보통 길이의 이름으로는 재현하지 못했고,
정확히 얼마나 긴 입력에서 바뀌는지는 확인하지 못했다.

플레이어에게는 접수대 프로그램의 실행 파일과 접속 주소를 전달한다. 프로그램을
직접 분석하거나, 접속해서 다양한 길이의 이름을 넣어 비교할 수 있다. 조사
대상은 이름 입력만으로 직원 전용 자료를 보이게 만드는 것이다.

::objective
이름 입력만으로 직원 전용 자료가 나오게 만들고, 그 안에 담긴 flag를 읽자.
::

::resources

- 대상 호스트: 문제 네트워크 안의 `app`, 포트 9100.
- 프로그램 파일: `files/vault` (실행 파일, 네트워크로 실행되는 것과 같은 프로그램).
- 프로토콜: 접속 후 이름 한 줄(줄바꿈 포함)을 보내면 인사말과 결과를 한 번에
  돌려주고 연결을 닫는다.
::

::submission
직원 전용 자료에 나타난 `pwnden{...}` 값을 제출하자. 실행 환경을 새로
준비하면 값이 바뀐다.
::
