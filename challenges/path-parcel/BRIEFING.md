::message{from="아직안잠"}
택배 접수 안내랑 운영 기록을 같은 곳에 보관하고 있어. 파일 이름을 받는 읽기 기능이 공개 폴더 밖까지 갈 수 있는지 봐 줘.
::

아직안잠은 작은 배송 대행 사이트를 정리하고 있다. 방문자는 파일명을 입력해 접수 안내를 읽는다.
공개 안내 문서는 `public` 폴더에, 운영자용 복구 기록은 별도 폴더에 보관돼 있다.

사이트는 입력한 이름을 공개 폴더 뒤에 붙여 파일을 찾는다. 아직안잠은 폴더를 나눠 둔 것만으로
운영 자료 접근도 구분되는지 확신하지 못한다. 실제 파일 조회 기능을 조사할 수 있도록
사이트와 공개된 보관 안내를 전달했다.

::objective
파일 읽기 기능으로 운영 복구 기록을 찾아, 그 안의 복구 키를 제출하자.
::

::resources
사이트의 `welcome.txt`는 접수 안내, `guide.txt`는 폴더 배치와 기록 파일명을 담고 있다.
공개 파일을 먼저 읽고, 사이트의 파일명 입력칸에서 다른 경로를 시도할 수 있다.
입력칸은 경로를 그대로 받는다. 응답 내용이 어떤 파일인지 확인하자.
::
