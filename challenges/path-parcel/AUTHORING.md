# 시나리오 작성 기록

## 현재 설명 구성 (2026-10-04)

기본 브리핑에는 상황·목표·범위·접근 정보·자료 위치·제출 대상을 둔다.
풀이자는 자료를 읽고 사용할 도구와 비교 기준을 선택한다. 선택형 힌트가 막힌
판단을 돕고, 해설이 재현 명령과 결론을 설명한다. 공통 개념은 학습 연결에서
필요할 때 읽는다. 명령 예제를 기본 본문에 제공했던 기존 설계의 시작 정보·판단·
힌트 평가는 재검토 대기이며, 새 본문에 대한 심사를 완료했다고 간주하지 않는다.

이하 검토·설계 기록은 작성 당시 버전의 근거다. 본문의 명령 예제나 조작 설명을
언급하는 과거 기록은 현재 기본 브리핑의 제공 정보로 사용하지 않는다.

## 2026-10-02 설명 검토

방문자 안내와 운영자 복구 문서의 접근 범위를 소개한다. 경로 검증은 실제 파일
위치를 계산한 뒤 공개 폴더 안에 있는지 확인하는 동작으로 설명한다.
이번 검토는 작성자가 구현과 설명을 대조한 범위이며 독립 풀이자 리뷰는 대기 상태다.

## 시나리오와 학습 목표

아직안잠이 배송 안내와 운영 자료를 정리하던 중 폴더 분리의 효과를 확인해 달라고 맡긴다. 평소 말하듯 조사 이유를 전한다.

- 대표 학습 분야: web-security
- 세부 주제: web-information-disclosure
- 계약 category: web
- 보안 학습 목표: 입력한 상대 경로가 실제 파일 읽기 범위를 벗어나는지 관찰하고 최종 폴더 경계 검증을 이해한다.
- 대상 풀이자: 브라우저 사용과 텍스트 읽기를 할 수 있으며 제공된 조작을 수행하는 사람.
- 플레이어 도구: web. 현재 계약 선언으로 공통 플랫폼 도구를 소비한다.

## 선수 능력과 개념 관계

- requires `web-addresses`: [공통 시작 지식](../../knowledge/web-addresses.md).
- requires `file-paths`: [공통 시작 지식](../../knowledge/file-paths.md).

BRIEFING.md의 개념 참조는 공통 지식을 배포용 README.md에 반영한다.
풀이자가 필요한 설명을 문제 본문에서 읽는다. teaches는 위 보안 학습 목표이며,
구체적인 공격 식과 결과는 힌트·해설에 배치한다.
Python 문법 읽기나 코드 작성은 일반 풀이의 선수 능력에 포함하지 않는다.

## 의도된 풀이와 관찰

1. 정상 공개 안내와 guide.txt를 읽어 폴더 관계를 찾는다.
2. public에서 ../private/recovery.txt를 구성한다.
3. 실제 운영 파일의 응답과 정상 공개 응답을 비교한다.

## 난도 근거

- 선언: 2 초급 (Easy).
- 제공된 예제로 상대 경로를 학습한 뒤 실제 폴더 배치와 파일명을 연결해 입력을 독립적으로 만든다. 코드 구현은 없지만 주소·폴더 정보를 합쳐 접근을 구성하는 부담을 고려해 초급으로 제안한다. 한 값 편집만 하는 입문 경로보다 추론이 추가된다.
- 이 평가는 기술 재현과 작성자 검토에 근거한 초안이다. 독립적인 대상 수준 풀이자의 관찰로 재평가한다.

## 대안과 자료 노출 범위

./../private/recovery.txt도 같은 위치다. 취약 대상은 다른 컨테이너 내부 파일의 읽기도 허용할 수 있다. 복구 키는 의도된 private 자료에 제공하며 컨테이너에 호스트 bind와 외부 네트워크를 추가하지 않는다. 생성 파일은 작은 컨테이너 tmpfs에만 둔다.

작성 기록과 풀이 스크립트는 작성자 자료이며 웹의 기본 본문·파일 도구는 선언한
플레이어 자료만 노출한다. 로컬 카탈로그 파일은 비밀 저장소로 취급하지 않는다.

## 기술 검증과 학습 리뷰

- 2026-10-02, Codex 작성·기술 검증. 최초 콘텐츠 구현 작업 트리 기준.
- 실제 HTTP의 두 상대 경로 풀이와 정상 파일을 확인했다. 패치는 정규화된 최종 위치를 폴더 경계로 비교한다. 상대·절대 경로와 public-other를 거절하며, 단위 검사에서 외부를 가리키는 공개 폴더의 symlink도 거절한다. 빈 입력·NUL·없는 파일의 상태를 확인했다.
- `python3 -B tools/verify.py path-parcel`: 고정 Python 3.13.15 이미지에서 풀이와 선언된 패치, 컨테이너·네트워크·볼륨 정리 통과.
- 작성자 내용 검토: 의뢰 맥락, 출발 정보, 완료 조건, 점진적 힌트와 해설의 보안 원리를 대조했다.
- Browser Plugin을 통한 실제 화면 조작 검증은 수행하지 않았다.
- 독립 학습 리뷰: 대상 수준 풀이자의 실제 리뷰는 아직 수행하지 않았다.
- 공개 준비: 기술 구현은 완료됐으며 독립 학습 리뷰와 난도 확인을 마친 뒤 공식 카탈로그로 공개한다.
