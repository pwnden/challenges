> “회원 검색에 점검용 화면을 붙였어. 이제 왜 검색되는지도 보이거든. 근데 비공개 회원까지 나온다는 제보가 왔네.”

식빵두쪽이 작은 커뮤니티의 회원 검색 데스크를 보내왔다.
검색창 아래에는 실제로 실행된 검색 조건이 표시된다. 비공개 회원의 소개에는 점검용 복구 키가 들어 있다.

## 의뢰 목표

검색 입력이 조건에 어떤 영향을 주는지 조사하고, 비공개 회원의 복구 키를 찾아 제출하자.

## 전달받은 정보

- 공개 회원 이름은 `mira`와 `sol`이다. 먼저 정상 검색을 확인해 보자.
- 검색창에는 이름을 입력한다. 아래에서 검색 조건과 결과를 함께 볼 수 있다.
- 비공개 회원은 `public = 0`, 공개 회원은 `public = 1`로 기록돼 있다.

## 시작 전 알아둘 것

SQL은 데이터베이스에 원하는 자료를 요청하는 언어다. 이 사이트에서는 다음 구조로 검색한다.

`SELECT name, note FROM members WHERE name = '입력한 이름' AND public = 1`

- `SELECT name, note`는 이름과 소개를 읽는다.
- `WHERE` 뒤는 결과에 포함할 조건이다.
- `'mira'`처럼 작은따옴표 안의 값은 문자 데이터다.
- `AND`는 양쪽 조건이 모두 참일 때, `OR`는 어느 한쪽이 참일 때 성립한다.

검색 조건에 표시된 입력의 위치와 따옴표를 관찰해 보자. 다음 검색에서는 입력과 결과를 비교하자.
이번 조사에서 필요한 추가 문법은 힌트와 사건 보고서에서 설명한다.

복구 키는 `pwnden{...}` 형식이다.
