::message{from="식빵두쪽"}
공개 회원만 검색되게 만들었거든. 그런데 검색어를 이상하게 넣으면 비공개 소개도 나온대. 어떤 입력에서 그런지 같이 봐줄래?
::

:person[식빵두쪽]이 만든 작은 커뮤니티에는 회원 이름으로 소개를 찾아보는 검색 페이지가 있다.
회원은 공개 여부를 정할 수 있고, 검색 결과에는 공개 회원의 이름과 소개만 나와야 한다.
비공개 회원의 소개는 다른 방문자에게 보여 주면 안 되는 자료다.

최근 식빵두쪽은 검색창에 특정한 값을 넣었더니 비공개 소개까지 보였다는 제보를 받았다.
평범한 이름으로 검색하면 공개 회원의 소개만 나온다. 식빵두쪽은 어떤 입력이 문제를
일으키는지 확인하려고 서버의 검색 조건을 화면에 표시해 두었다. 네가 입력한 검색어가 어떤 조건으로
바뀌는지, 그 조건으로 어떤 결과가 나오는지 함께 살펴볼 수 있다.

조사용 사이트의 비공개 회원 소개에는 계정을 복구할 때 필요한 비밀값인 복구 키가 들어 있다. 검색을 통해 이 키를 읽을 수
있다면, 공개 여부를 검사해야 할 검색 기능이 비밀 자료를 노출한 것이다.
식빵두쪽은 그 상황을 직접 재현해 달라고 길드에 의뢰했다.

::objective

검색 입력이 조건에 어떤 영향을 주는지 조사하고, 비공개 회원의 복구 키를 찾아 제출하자.
::

::resources

- 공개 회원 이름은 `mira`와 `sol`이다.
- 사이트에는 이름 검색창과 실제 검색 조건 표시가 있다.
::


::submission
복구 키는 `pwnden{...}` 형식이다. 실행 환경을 새로 준비하면 값이 바뀌므로,
현재 검색 결과에서 찾은 값을 제출하자.
::
