# 시나리오 작성 기록

## 현재 설명 구성 (2026-10-04)

기본 브리핑에는 상황·목표·범위·접근 정보·자료 위치·제출 대상을 둔다.
풀이자는 자료를 읽고 사용할 도구와 비교 기준을 선택한다. 선택형 힌트가 막힌
판단을 돕고, 해설이 재현 명령과 결론을 설명한다. 공통 개념은 학습 연결에서
필요할 때 읽는다. 명령 예제를 기본 본문에 제공했던 기존 설계의 시작 정보·판단·
힌트 평가는 재검토 대기이며, 새 본문에 대한 심사를 완료했다고 간주하지 않는다.

이하 검토·설계 기록은 작성 당시 버전의 근거다. 본문의 명령 예제나 조작 설명을
언급하는 과거 기록은 현재 기본 브리핑의 제공 정보로 사용하지 않는다.

## 2026-10-02 설명 검토

데이터베이스와 SQL을 소개한 뒤 검색 조건을 읽게 하고, 힌트·해설의 따옴표와
주석 동작을 일상적인 말로 설명했다. 복구 키의 용도도 제공한다.
이번 검토는 작성자가 구현과 설명을 대조한 범위이며 독립 풀이자 리뷰는 대기 상태다.

## 시나리오 설정

- 한 줄 소개와 목소리: 식빵두쪽이 검색 점검 화면을 자신 있게 만들었다가 비공개 회원 노출 제보를 받고 재검증을 맡긴다. 짧은 반말에 가벼운 자조를 사용한다.
- 길드를 찾은 이유: 사용자 입력이 실제 검색 조건에서 어떻게 작동하는지 다른 눈으로 확인하고 싶어 길드에 검색 대상을 제공한다.
- 플레이어의 역할: 제공된 로컬 대상 또는 배포 자료를 조사하는 길드 조사자.
- 목표와 완료 증거: 검색 입력의 작은따옴표가 SQL 구조를 바꾸는 것을 관찰하고 비공개 자료를 읽는다. 데이터와 명령 구조의 경계를 설명한다.
- 공개 정보는 README.md, 단계별 발견은 hints/, 완전한 재현은 solve/README.md에 둔다.
- 등장인물은 이번 의뢰의 짧은 설정으로 사용한다. 별도 이야기 저장소의 구조는 후속 설계에서 정한다.

## 학습 목표와 대상

- 계약 category: web
- 학습 분야: web-security
- 세부 주제: web-injection
- 보안 학습 목표: 검색 입력의 작은따옴표가 SQL 구조를 바꾸는 것을 관찰하고 비공개 자료를 읽는다. 데이터와 명령 구조의 경계를 설명한다.
- 대상 풀이자: 검색 폼과 결과를 비교하고 본문에 설명된 SELECT·WHERE·따옴표·AND·OR를 읽는 풀이자. SQL 작성 경험은 필수로 두지 않는다.
- category 근거: 위 학습 주제를 현재 계약의 가장 가까운 분류로 표시한다.
- 도구: web. 이 선언으로 기존 플랫폼 공통 기능을 소비한다.

## 선수 지식과 학습 내용

시작 능력은 브라우저 사용과 텍스트 입력·읽기다. 이번 문제에서 필요한 추가 용어와
조작은 README.md의 전달받은 정보와 시작 전 알아둘 것에서 설명한다.
SQL 조건식은 본문과 추가 정보의 범위 안에서 학습한다. Python 같은 범용 프로그래밍
언어의 지식이나 풀이 프로그램 작성 능력은 선수 조건으로 두지 않는다.

## 난도 근거

- 선언한 값: 2 초급
- 전체 풀이 부담: 본문 설명과 쿼리 표시로 시작할 수 있지만, 기본 화면만으로 풀려면 문자 경계·참 조건·나머지 조건 제거를 연결해야 한다. 입문의 단일 안내 실험보다 추론 부담이 크고, 중급의 여러 취약점 연결이나 스크립팅은 없다. 학습 리뷰 후 재평가한다.
- 구현 부담: 준비된 도구의 입력과 자료 관찰. 풀이 코드 구현은 요구하지 않는다.
- 등급은 아래의 독립 학습 리뷰 결과에 따라 재검토한다.

## 다른 풀이와 정답 노출

항상 참인 OR 조건과 비공개 여부를 직접 고르는 OR 조건을 모두 검증한다. keeper의 정상 이름 검색으로는 정답을 읽을 수 없다. HTML 출력은 escape한다.

풀이자에게 필요한 사전 설명은 기본 브리핑에 둔다. 로컬 카탈로그의 작성자 파일은
비밀 저장소로 취급하지 않으며, 사이트의 기본 파일 도구에는 배포 자료만 선언한다.

## 검증과 리뷰

- 실행 범위: 실제 SQLite 메모리 데이터베이스와 HTTP 검색 폼. 조건식과 주석이 SQLite에서 평가된다. 패치는 매개변수 쿼리를 사용한다.
- 기술 확인 범위: 정상 검색, 비공개 검색 차단, 잘못된 따옴표, 두 공격 식, 실제 폼 결과를 검사한다. 패치에서는 공격·긴 입력·문자 이스케이프와 정상 회원 검색을 확인한다.
- 기술 검증: 2026-10-02, 이 파일을 포함한 최초 콘텐츠 제출 버전. 호스트 Python 3.14.7, 풀이 이미지 Python 3.13.15, Docker 29.4.1, Compose 5.1.3에서 형식 검사, 전체 6개 문제 풀이·선언된 패치·정리 검사와 47개 회귀 검사를 통과했다.
- 격리 검증: 도달 가능한 대조군을 확인한 뒤 외부 IPv4·IPv6·DNS, 호스트와 별도 문제 네트워크 접근 차단, 같은 문제 내부 HTTP 성공 및 대조군 정리를 확인했다.
- 내용 검토: Codex가 초기 사용자 관점으로 배경·단계별 단서·해설·정답 노출을 검토했다. 독립 학습 리뷰와는 구분한다.
- 맥락 보완: 2026-10-02, Codex가 정상 회원 검색·비공개 소개·노출 제보·검색 조건 표시 화면의 관계를 본문에 연결했다. 공개 계정과 public 값, 검색 결과·조건 표시, 키 생성 동작을 대상 코드에 대조했다.
- 독립 학습 리뷰: 대상 수준 풀이자의 실제 리뷰는 아직 수행하지 않았다.
- 공개 준비 상태: 기술 검증과 별도로 독립 학습 리뷰와 난도 확인을 마친 뒤 공개한다.
