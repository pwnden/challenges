::message{from="잔비"}
제가 운영하는 웹 보관소를 이전하면서 자료를 백업했어요. 백업에는 운영자만 알아야 하는 복구 키도 들어 있는데, 일반 방문자가 아직 백업 파일을 읽을 수 있다는 제보를 받았어요. 보관소 주소와 백업 파일 이름을 보내 드릴게요. 일반 방문자로 접속해서 백업의 복구 키까지 읽을 수 있는지 확인해 주세요.
::

:person[잔비]는 문을 닫은 팬사이트와 개인 홈페이지의 흔적을 모으는 작은 웹 보관소를
돌보고 있다. 최근 보관소를 옮기면서 기존 자료를 백업 파일로 내보냈고,
작업이 끝난 뒤에는 방문자가 보는 목록에서 백업 파일로 가는 링크를 뺐다.
백업은 기존 자료를 다시 복원할 수 있도록 복사해 둔 파일이다.

그런데 누군가 여전히 백업 파일을 읽을 수 있다고 알려 왔다. 잔비는 목록을
둘러봐도 그 파일을 찾을 수 없어, 방문자가 어디로 들어가야 백업을 볼 수 있는지
길드에 확인을 맡겼다. 백업에는 사이트를 복구할 때 필요한 비밀값인 복구 키까지 들어 있다.
방문자가 백업 파일을 받을 수 있다면 복구 키도 읽을 수 있다.

잔비는 일반 방문자도 접속할 수 있는 보관소 주소와 이전 작업 때 사용한 파일 이름을 전달했다.
사이트에 남아 있는 안내를 살펴보고, 백업에 실제로 접근할 수 있는지 조사해 보자.

::objective

공개 웹사이트에서 백업을 찾아 읽고, 그 안의 복구 키를 제출하자.
::

::resources

- 웹 도구에서 보관소에 접속할 수 있다.
- 이전 작업에서 만든 백업 파일의 이름은 `site-backup.txt`다.
::


::submission
복구 키는 `pwnden{...}` 형식이다. 실행 환경을 새로 준비하면 값이 바뀌므로,
현재 보관소에서 읽은 값을 제출하자.
::
