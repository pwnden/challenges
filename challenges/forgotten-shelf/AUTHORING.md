# 시나리오 작성 기록

## 2026-10-02 설명 검토

백업과 복구 키의 용도를 설명하고 검색 서비스의 안내 파일을 확인하는 동작을 맞췄다.
이번 검토는 작성자가 구현과 설명을 대조한 범위이며 독립 풀이자 리뷰는 대기 상태다.

## 시나리오 설정

- 한 줄 소개와 목소리: 잔비가 보관소 이전 후 공개 백업 노출을 점검해 달라고 의뢰한다. 짧은 존댓말로 자신의 조치와 확인하지 못한 부분을 전달한다.
- 길드를 찾은 이유: 공개 목록을 정리한 뒤 자료가 읽힌다는 제보를 받고, 경로를 직접 조사할 사람을 찾았다.
- 플레이어의 역할: 제공된 로컬 대상 또는 배포 자료를 조사하는 길드 조사자.
- 목표와 완료 증거: 공개 수집 안내와 파일 이름을 연결해 백업에 접근하고, 링크 제거와 서버 접근 통제의 차이를 설명한다.
- 공개 정보는 README.md, 단계별 발견은 hints/, 완전한 재현은 solve/README.md에 둔다.
- 등장인물은 이번 의뢰의 짧은 설정으로 사용한다. 별도 이야기 저장소의 구조는 후속 설계에서 정한다.

## 학습 목표와 대상

- 계약 category: web
- 학습 분야: web-security
- 세부 주제: web-information-disclosure
- 보안 학습 목표: 공개 수집 안내와 파일 이름을 연결해 백업에 접근하고, 링크 제거와 서버 접근 통제의 차이를 설명한다.
- 대상 풀이자: 브라우저에서 주소를 입력하고 텍스트를 읽는 풀이자. 경로와 robots.txt의 의미는 본문에서 배운다.
- category 근거: 위 학습 주제를 현재 계약의 가장 가까운 분류로 표시한다.
- 도구: web. 이 선언으로 기존 플랫폼 공통 기능을 소비한다.

## 선수 지식과 학습 내용

시작 능력은 브라우저 사용과 텍스트 입력·읽기다. 이번 문제에서 필요한 추가 용어와
조작은 README.md의 전달받은 정보와 시작 전 알아둘 것에서 설명한다.
프로그래밍 언어 문법을 읽거나 코드를 작성하는 능력을 풀이의 선수 조건으로 두지 않는다.

## 의도된 풀이

| 단계 | 행동 | 관찰 | 필요한 지식·도구 |
| --- | --- | --- | --- |
| 1 | 운영 안내와 전달 정보를 읽는다 | 백업 파일 이름과 수집 안내 위치 | 웹 도구, 경로 설명 |
| 2 | robots.txt를 연다 | Disallow에 기록된 /archive/ | 수집 안내 읽기 |
| 3 | 경로에 파일 이름을 붙여 연다 | 현재 실행의 recovery_key | 텍스트 응답 관찰 |

대상 구현과 자동 검증에는 Python을 사용한다. 풀이자가 사용할 경로와 도구는 위 표를 따른다.

## 개념 관계

선수 능력과 새로운 학습 목표를 위에서 구분하고 `[learning]`에 개념 ID로 선언한다.
공통 정의는 `knowledge/catalog.toml`을 따른다. 플랫폼은 이 선언으로 선행·후속
문제와 선수 지식 문서를 연결하며 본문의 배경 설명도 함께 제공한다.
분야·세부 주제의 의미는 [학습 지도](../../docs/learning-map.md)를 따른다.
구체적인 공격 식과 정답은 추가 정보와 사건 보고서에서 공개한다.

## 난도 근거

- 선언한 값: 1 입문
- 전체 풀이 부담: 본문에 경로 입력·수집 안내·파일 이름을 제공한다. 한 번의 경로 조합으로 공개 노출을 관찰하며 코딩이나 계정 조작이 없다. 초급과 달리 수집 안내를 미리 알고 있어야 할 필요가 없다.
- 구현 부담: 준비된 도구의 입력과 자료 관찰. 풀이 코드 구현은 요구하지 않는다.
- 등급은 아래의 독립 학습 리뷰 결과에 따라 재검토한다.

## 다른 풀이와 정답 노출

전달받은 파일 이름으로 직접 백업 경로에 접근해도 같은 노출을 입증한다. 루트와 운영 안내에는 정답을 표시하지 않는다.

풀이자에게 필요한 사전 설명은 기본 브리핑에 둔다. 로컬 카탈로그의 작성자 파일은
비밀 저장소로 취급하지 않으며, 사이트의 기본 파일 도구에는 배포 자료만 선언한다.

## 검증과 리뷰

- 실행 범위: 실제 로컬 HTTP 대상. 새 플래그를 환경으로 받아 텍스트 백업에 기록한다. 패치는 공개 백업 경로를 제외한다.
- 기술 확인 범위: 실제 백업 응답과 형식, 루트에서 정답 미노출, 패치의 동일 경로 공격 차단, 공개 페이지·건강 상태·없는 경로를 검사한다.
- 기술 검증: 2026-10-02, 이 파일을 포함한 최초 콘텐츠 제출 버전. 호스트 Python 3.14.7, 풀이 이미지 Python 3.13.15, Docker 29.4.1, Compose 5.1.3에서 형식 검사, 전체 6개 문제 풀이·선언된 패치·정리 검사와 47개 회귀 검사를 통과했다.
- 격리 검증: 도달 가능한 대조군을 확인한 뒤 외부 IPv4·IPv6·DNS, 호스트와 별도 문제 네트워크 접근 차단, 같은 문제 내부 HTTP 성공 및 대조군 정리를 확인했다.
- 내용 검토: Codex가 초기 사용자 관점으로 배경·단계별 단서·해설·정답 노출을 검토했다. 독립 학습 리뷰와는 구분한다.
- 맥락 보완: 2026-10-02, Codex가 보관소의 용도·이전 작업·백업 노출 제보·복구 키를 조사할 이유를 본문에 연결했다. 운영 안내·파일 이름·수집 안내·키 생성 동작을 대상 코드에 대조했다.
- 독립 학습 리뷰: 대상 수준 풀이자의 실제 리뷰는 아직 수행하지 않았다.
- 공개 준비 상태: 기술 검증과 별도로 독립 학습 리뷰와 난도 확인을 마친 뒤 공개한다.
