## 조사 결과

검색 로봇 안내의 폴더 경로에 백업 파일 이름을 붙이자, 공개 목록에 없는 복구 키를 읽을 수 있었다.

## 조사 과정

1. 보관소의 운영 안내에서 검색 로봇의 안내 파일과 백업 이름을 확인한다.
2. 웹 도구에서 `/robots.txt`를 연다. `Disallow: /archive/`가 기록돼 있다.
3. 파일 이름을 붙여 `/archive/site-backup.txt`로 이동한다.
4. 자료의 `recovery_key=` 다음에 현재 복구 키가 표시된다.

## 의뢰 완료 확인

`recovery_key=` 뒤의 `pwnden{...}` 전체를 제출한다. 복구 키는 실행할 때마다 새로 만들어지므로
현재 실행 중인 사이트에서 읽은 값을 사용한다.

## 드러난 보안 원리

공개 목록에서 링크를 없애도 해당 경로를 처리하는 서버 동작은 남을 수 있다.
`robots.txt`는 수집 규칙을 공개하는 파일이다. 경로에 대한 접근 권한은 서버가 따로 확인해야 한다.

이 대상은 백업 경로에서 접근 확인 없이 자료를 반환했다. 수정된 대상은 백업을 공개 경로에서
제외하고, 운영 안내와 공개 보관소는 계속 제공한다. 비밀이 포함된 백업은 공개 웹
폴더 밖에 보관하고 필요한 접근 권한을 적용해야 한다.
