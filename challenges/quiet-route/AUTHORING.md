# 모든 경로가 200을 반환하는 서버 작성 기록

## 목표와 선수 능력

흐린응답은 보드 담당자다. 상태만 수집한 제보로는 실제 유출을 확정할 수 없어
본문을 비교하는 재검증을 맡긴다. 공개 정책은 도움말·상태만 허용한다.

- 분야 `web-security`, 주제 `web-information-disclosure`, category `web`.
- teaches: 응답 코드와 크기는 후보 탐색에 쓰고 실제 공개 적합성은 본문으로 판단한다.
- requires `terminal-commands`, `http-messages`, `response-comparison`: 출력 저장·
  상태·크기·cmp·FUZZ·필터·작업 및 시간 제한을 브리핑에 설명한다.
- 난도 2 초급: 기본 요청을 입력할 수 있는 학습자가 기준 응답을 찾고 후보를
  정책과 비교한다. URL 발견만으로는 완료되지 않는다. Python 작성은 필요 없다.

## 실제 대상과 관찰

stdlib HTTP 서비스 하나가 고정 JSON fallback을 200으로 반환한다. 12개 후보
중 help·healthz는 공개 기능, ops-check만 민감한 자료다. 정책 모듈 하나가
민감한 경로를 허용하거나 거부한다. 입력값·헤더의 역할 주장으로 우회하지 않는다.

1. 서로 다른 없는 주소의 200·같은 본문을 확인한다.
2. 안내와 민감한 자료가 모두 256바이트임을 확인하고, 안내 표시를 -fr로 제외한다.
3. 실제 JSON의 용도·대상을 공개 정책과 비교해 flag를 회수한다.
4. 수정 후 민감한 경로는 403이며 기존 공개 기능과 fallback은 유지된다.

해답은 curl·ffuf·jq를 사용하며 수정 서버의 거부에서 계약상 코드 3을 반환한다.
패치 검사는 동일 fallback, 공개 기능·후보 포함, 민감한 경로와 역할 헤더·query의
거부를 실제 HTTP로 확인한다. 두 worker·초당 10건·15초 상한을 사용한다.
해답과 패치 검사는 크기 필터가 자료 경로를 숨기는 대조 결과도 확인한다.
공통 basic 이미지와 작은 stdlib 대상만 필요하며 실행 중 설치는 없다.
