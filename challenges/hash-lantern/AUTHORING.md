# 시나리오 작성 기록

## 2026-10-02 설명 검토

백업 장치의 로그인 정보와 후보 비밀번호를 먼저 소개하고 해시를 계산 결과로 설명한다.
해설은 실제 후보 비교와 비밀번호 저장의 추가 값·계산 시간을 풀어 쓴다.
이번 검토는 작성자가 자료와 설명을 대조한 범위이며 독립 풀이자 리뷰는 대기 상태다.

## 시나리오와 학습 목표

moru17이 오래된 백업 장치를 다시 쓰려는 소유자로서 계정 기록과 비밀번호 메모를 전달한다. 사정을 풀어 말하는 존댓말을 사용한다.

- 대표 학습 분야: cryptographic-security
- 세부 주제: crypto-hashes-authentication
- 계약 category: crypto
- 보안 학습 목표: 빠른 해시만 저장한 약한 비밀번호를 짧은 후보 목록으로 확인하고 후보 대입 비용을 관찰한다.
- 대상 풀이자: 브라우저 사용과 텍스트 읽기를 할 수 있으며 제공된 조작을 수행하는 사람.
- 플레이어 도구: files, terminal. 현재 계약 선언으로 공통 플랫폼 도구를 소비한다.

## 선수 능력과 개념 관계

- requires `terminal-commands`: [공통 시작 지식](../../knowledge/terminal-commands.md).
- requires `hashing`: [공통 시작 지식](../../knowledge/hashing.md).

BRIEFING.md의 개념 참조는 공통 지식을 배포용 README.md에 반영한다.
풀이자가 필요한 설명을 문제 본문에서 읽는다. teaches는 위 보안 학습 목표이며,
구체적인 공격 식과 결과는 힌트·해설에 배치한다.
Python 문법 읽기나 코드 작성은 일반 풀이의 선수 능력에 포함하지 않는다.

## 의도된 풀이와 관찰

1. 계정의 알고리즘·salt·해시와 후보 여섯 개를 읽는다.
2. 준비된 printf | sha256sum 명령으로 각 후보를 비교한다.
3. 유일하게 맞는 비밀번호를 그대로 제출한다. 후보 자체가 완성된 `pwnden{...}` 문자열이다.

## 난도 근거

- 선언: 1 입문 (Intro).
- 명령 입력과 결과 비교를 본문에서 설명하고 후보는 여섯 개로 제한한다. 코드 작성·반복문·수학과 후보 목록 추정은 요구하지 않는다. 하나의 보안 개념을 준비된 명령으로 체험하므로 입문으로 제안한다.
- 이 평가는 기술 재현과 작성자 검토에 근거한 초안이다. 독립적인 대상 수준 풀이자의 관찰로 재평가한다.

## 대안과 자료 노출 범위

다른 SHA-256 도구도 동일한 UTF-8 입력을 줄바꿈 없이 해시하면 된다. 짧은 후보 목록은 제한된 실험을 위한 증거다. 일반 해시의 역함수나 모든 비밀번호의 빠른 복원을 주장하지 않는다. 여섯 후보 모두 같은 제출 형식을 사용하므로 형식만으로 정답을 고를 수 없다.

작성 기록과 풀이 스크립트는 작성자 자료이며 웹의 기본 본문·파일 도구는 선언한
플레이어 자료만 노출한다. 로컬 카탈로그 파일은 비밀 저장소로 취급하지 않는다.

## 기술 검증과 학습 리뷰

### 2026-10-04 직접 제출 검증

후보 여섯 개 모두 완성된 `pwnden{...}` 비밀번호다. 전체 문자열의 SHA-256이
계정 기록과 일치하는 후보는 하나이며, 내부 단어만 해시하면 일치하지 않는다.
`python3 -B -m unittest discover -s tools -p test_second_experiments.py`의 7개 검사가 통과했다.
`python3 -B tools/verify.py hash-lantern signed-delivery`에서 실제 선언 이미지의
해답과 정리 검사가 통과했다. 정답은 찾은 비밀번호 그 자체다. 후보 대입 비용의
정량 비교나 실제 초보자 관찰은 이번 변경에서 수행하지 않았다.

### 이전 판본의 검증 기록

- 2026-10-02, Codex 작성·기술 검증. 최초 콘텐츠 구현 작업 트리 기준.
- 검증 풀이가 실제 이미지의 sha256sum을 호출해 유일한 후보와 선언한 제출 해시를 확인했다. 계정·후보는 authoring/build.py로 재생성한다. 회귀 검사가 배포 자료의 후보 유일성과 manifest 해시 일치를 확인한다.
- `python3 -B tools/verify.py hash-lantern`: 고정 Python 3.13.15 이미지에서 풀이와 선언된 패치, 컨테이너·네트워크·볼륨 정리 통과.
- 작성자 내용 검토: 의뢰 맥락, 출발 정보, 완료 조건, 점진적 힌트와 해설의 보안 원리를 대조했다.
- Browser Plugin을 통한 실제 화면 조작 검증은 수행하지 않았다.
- 독립 학습 리뷰: 대상 수준 풀이자의 실제 리뷰는 아직 수행하지 않았다.
- 공개 준비: 기술 구현은 완료됐으며 독립 학습 리뷰와 난도 확인을 마친 뒤 공식 카탈로그로 공개한다.
