# 시나리오 작성 기록

## 2026-10-02 설명 검토

표시 제목은 Shared Files다. 팀 문서 사이트에서 팀원이 읽을 수 있는 자료와
운영자 문서를 비교하도록 대사·본문·사이트·힌트·해설을 맞췄다.
접근 규칙의 각 필드는 문서 읽기 동작으로 설명한다. 식별자는 기존 상태와 호환한다.
이번 검토는 작성자가 구현과 설명을 대조한 범위이며 독립 풀이자 리뷰는 대기 상태다.

## 시나리오와 학습 목표

잔비는 팀 문서 사이트의 접근 권한을 설정한 사람이다. 팀원에게 운영자의 복구 문서까지 공개되는지 조사 의뢰한다. 조심스러운 존댓말을 사용한다.

- 대표 학습 분야: cloud-infrastructure-security
- 세부 주제: cloud-identity-policies
- 계약 category: misc
- 보안 학습 목표: 동작·리소스 패턴이 실제 접근에 적용되는 범위를 확인하고 광범위한 wildcard 허용을 좁힌다.
- 대상 풀이자: 브라우저 사용과 텍스트 읽기를 할 수 있으며 제공된 조작을 수행하는 사람.
- 플레이어 도구: web. 현재 계약 선언으로 공통 플랫폼 도구를 소비한다.

## 선수 능력과 개념 관계

- requires `resource-policies`: [공통 시작 지식](../../knowledge/resource-policies.md).

BRIEFING.md의 개념 참조는 공통 지식을 배포용 README.md에 반영한다.
풀이자가 필요한 설명을 문제 본문에서 읽는다. teaches는 위 보안 학습 목표이며,
구체적인 공격 식과 결과는 힌트·해설에 배치한다.
Python 문법 읽기나 코드 작성은 일반 풀이의 선수 능력에 포함하지 않는다.

## 의도된 풀이와 관찰

1. team-reader로 정상 공유 노트를 읽는다.
2. 현재 read 동작과 locker/team-* 패턴을 분석한다.
3. 이름이 맞는 운영 리소스와 맞지 않는 개인 리소스를 비교한다.

## 난도 근거

- 선언: 2 초급 (Easy).
- 정책의 세 요소와 wildcard 예제는 시작 지식에 제공한다. 풀이자는 리소스 목록과 규칙을 결합해 허용 범위를 독립적으로 비교한다. 간단한 정책 읽기와 정상·거절·의도하지 않은 성공의 세 관찰을 고려해 초급으로 제안한다.
- 이 평가는 기술 재현과 작성자 검토에 근거한 초안이다. 독립적인 대상 수준 풀이자의 관찰로 재평가한다.

## 대안과 자료 노출 범위

직접 조회 주소의 resource 값을 바꿔도 같은 평가를 받는다. 서버는 고정된 team-reader 정책을 평가한다. JSON 전체를 수정하거나 실제 클라우드 계정을 쓰는 경로는 필요하지 않다. 기본 정책과 목록은 키 값을 포함하지 않는다.

작성 기록과 풀이 스크립트는 작성자 자료이며 웹의 기본 본문·파일 도구는 선언한
플레이어 자료만 노출한다. 로컬 카탈로그 파일은 비밀 저장소로 취급하지 않는다.

## 기술 검증과 학습 리뷰

- 2026-10-02, Codex 작성·기술 검증. 최초 콘텐츠 구현 작업 트리 기준.
- 실제 공유 노트 성공, 개인 초안 거절, 운영 리소스 성공과 패치 거절을 확인했다. 좁힌 정책에서도 정상 노트는 유지된다. 단위 검사는 정확한 동작 비교, 기본 거절과 명시적 Deny 우선을 확인했다. 이 평가는 명시한 로컬 부분집합이며 특정 공급자의 전체 정책 의미를 주장하지 않는다.
- `python3 -B tools/verify.py borrowed-badge`: 고정 Python 3.13.15 이미지에서 풀이와 선언된 패치, 컨테이너·네트워크·볼륨 정리 통과.
- 작성자 내용 검토: 의뢰 맥락, 출발 정보, 완료 조건, 점진적 힌트와 해설의 보안 원리를 대조했다.
- Browser Plugin을 통한 실제 화면 조작 검증은 수행하지 않았다.
- 독립 학습 리뷰: 대상 수준 풀이자의 실제 리뷰는 아직 수행하지 않았다.
- 공개 준비: 기술 구현은 완료됐으며 독립 학습 리뷰와 난도 확인을 마친 뒤 공식 카탈로그로 공개한다.
