## 2026-10-02 설명 검토

표시 제목은 팀 문서의 읽기 권한이다. 팀 문서 사이트에서 팀원이 읽을 수 있는 자료와
운영자 문서의 현재·과거 본문을 비교하도록 대사·본문·사이트·힌트·해설을 맞췄다.
접근 규칙의 각 필드는 문서와 요청 동작의 조합으로 설명한다. 식별자는 기존 상태와 호환한다.
이번 검토는 작성자가 구현과 설명을 대조한 범위이며 독립 풀이자 리뷰는 대기 상태다.

## 시나리오와 학습 목표

잔비는 팀 문서 사이트의 접근 권한을 설정한 사람이다. 팀원에게 운영자의 복구 문서까지 공개되는지 조사 의뢰한다. 조심스러운 존댓말을 사용한다.

- 대표 학습 분야: cloud-infrastructure-security
- 세부 주제: cloud-identity-policies
- 계약 category: misc
- 보안 학습 목표: 넓은 동작 허용과 좁은 거절이 결합됐을 때 현재 본문과 과거 본문의 접근 결과가 달라짐을 추론한다. 데이터의 모든 읽기 경로에 권한 검사를 적용한다.
- 대상 풀이자: 브라우저 사용과 텍스트 읽기를 할 수 있으며 제공된 조작을 수행하는 사람.
- 플레이어 도구: web. 현재 계약 선언으로 공통 플랫폼 도구를 소비한다.

Python 문법 읽기나 코드 작성은 일반 풀이의 선수 능력에 포함하지 않는다.

## 의도된 풀이와 관찰

1. team-reader로 정상 공유 노트를 읽는다.
2. 운영 문서의 현재 읽기가 거절되는 것을 확인한다.
3. 공유 노트의 기록 요청에서 read-history와 read-version 동작을 확인한다.
4. read* 허용과 read 거절이 각 동작에 맞는지 비교한다.
5. 운영 문서의 과거 기록을 요청해 첫 작성 본문에 남은 키를 복구한다.

## 난도 근거

- 선언: 2 초급 (Easy).
- 정책 항목과 패턴은 시작 지식에서 설명한다. 공유 노트의 정상 기능과 운영 문서의 거절을 관찰한 뒤, 요청 동작과 거절 규칙의 적용 범위를 비교해 별도 읽기 경로를 찾아야 한다. 정책 비교와 과거 버전 선택의 추론을 근거로 초급으로 제안한다.
- 이 평가는 기술 재현과 작성자 검토에 근거한 초안이다. 독립적인 대상 수준 풀이자의 관찰로 재평가한다.

## 대안과 자료 노출 범위

서버는 고정된 team-reader 정책을 평가한다. 현재 문서 읽기는 운영 문서 이름을 입력해도 거절된다. 공유 노트의 기록 요청 주소를 관찰해 문서 이름을 바꾸는 경로로 조사할 수 있다. 기본 정책·목록·기록 제목에는 키를 포함하지 않는다. 실제 클라우드 계정이나 Python 문법은 풀이에 필요하지 않다.

힌트는 1개다. 같은 문서에 여러 동작이 적용되는 지점의 추론을 돕는다.
정확한 요청과 과거 버전 선택은 해설에서 공개한다.

작성 기록과 풀이 스크립트는 작성자 자료이며 웹의 기본 본문·파일 도구는 선언한
플레이어 자료만 노출한다. 로컬 카탈로그 파일은 비밀 저장소로 취급하지 않는다.

## 기술 검증과 학습 리뷰

- 2026-10-02, Codex 작성·기술 검증. 최초 콘텐츠 구현 작업 트리 기준.
- 기술 확인 항목: 공유 노트의 현재·과거 본문 성공, 운영 현재 본문 거절, 기록 목록과 과거 본문 성공, 최근 기록에 키 없음, 패치에서 모든 운영 읽기 거절과 정상 공유 기능 유지.
- 단위 검사는 동작·리소스 패턴, 기본 거절과 Deny 우선을 확인한다. 이 사이트는 명시한 로컬 정책 부분집합이며 특정 공급자의 전체 정책 의미를 주장하지 않는다.
- `python3 -B tools/verify.py borrowed-badge`: 재설계한 작업 트리에서 실제 풀이, 패치 공격 거절, 정상 현재·과거 읽기 유지, 자원 정리 통과. 고정 Python 3.13.15 이미지로 실행했다.
- 작성자 내용 검토: 의뢰 맥락, 출발 정보, 완료 조건, 선택적 힌트와 해설의 보안 원리를 대조했다.
- Browser Plugin을 통한 실제 화면 조작 검증은 수행하지 않았다.
- 독립 학습 리뷰: 대상 수준 풀이자의 실제 리뷰는 아직 수행하지 않았다.
- 공개 준비: 기술 구현은 완료됐으며 독립 학습 리뷰와 난도 확인을 마친 뒤 공식 카탈로그로 공개한다.
