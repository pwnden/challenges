::message{from="잔비"}
팀 읽기 배지를 새로 만들었는데, 이름이 비슷한 운영 보관소까지 권한이 붙은 것 같아요. 실제로 어떤 규칙이 적용되는지 확인해 줄래요?
::

잔비는 팀 자료를 새 보관소로 옮기면서 팀원이 쓸 읽기 배지를 만들었다.
팀원은 공유 작업 노트를 읽을 수 있고, 운영 복구 키와 개인 초안은 각각 별도 권한으로 관리한다.

전달된 사이트는 이 배지의 권한 정책을 평가하는 로컬 실험용 보관소다.
리소스 목록과 현재 역할의 정책을 보여 주며, 입력한 리소스에 읽기 요청을 보낼 수 있다.
표시 이름과 실제 정책 범위가 일치하는지 조사해 달라는 의뢰다.

::objective
팀 읽기 역할로 운영자용 리소스를 읽을 수 있는지 확인하고, 그 안의 복구 키를 제출하자.
::

::resources
현재 역할은 `team-reader`다. `locker/team-notes`가 정상적인 팀 공유 자료다.
사이트의 목록에는 각 리소스의 전체 이름과 용도가 적혀 있다.
현재 정책을 읽고 리소스 입력칸에서 접근 결과를 비교하자.
::
