# 시나리오 작성 기록

## 현재 설명 구성 (2026-10-04)

기본 브리핑에는 상황·목표·범위·접근 정보·자료 위치·제출 대상을 둔다.
풀이자는 자료를 읽고 사용할 도구와 비교 기준을 선택한다. 선택형 힌트가 막힌
판단을 돕고, 해설이 재현 명령과 결론을 설명한다. 공통 개념은 학습 연결에서
필요할 때 읽는다. 명령 예제를 기본 본문에 제공했던 기존 설계의 시작 정보·판단·
힌트 평가는 재검토 대기이며, 새 본문에 대한 심사를 완료했다고 간주하지 않는다.

이하 검토·설계 기록은 작성 당시 버전의 근거다. 본문의 명령 예제나 조작 설명을
언급하는 과거 기록은 현재 기본 브리핑의 제공 정보로 사용하지 않는다.

## 2026-10-02 설명 검토

제작실 문서 사이트의 게스트·운영자 권한과 브라우저의 사용자 구분 값을 설명한다.
복구 키의 용도, 쿠키와 세션의 뜻을 제공하고 실제 사이트 문구도 맞췄다.
이번 검토는 작성자가 구현과 설명을 대조한 범위이며 독립 풀이자 리뷰는 대기 상태다.

## 시나리오와 학습 목표

식빵두쪽은 공동 제작실에 초대된 게스트다. 문서 사이트가 브라우저의 사용자 구분 값만으로 운영자 자료를 보여 주는지 확인해 달라고 맡긴다. 존댓말로 관찰과 요청을 전한다.

- 대표 학습 분야: web-security
- 세부 주제: web-authentication-sessions
- 계약 category: web
- 보안 학습 목표: 브라우저 쿠키의 사용자 구분 값을 바꾸고 서버의 접근 권한 판단을 관찰한다.
- 대상 풀이자: 브라우저 사용과 텍스트 읽기를 할 수 있으며 제공된 조작을 수행하는 사람.
- 플레이어 도구: web. 현재 계약 선언으로 공통 플랫폼 도구를 소비한다.

## 의도된 풀이와 관찰

1. guest의 키 조회가 403인 것을 확인한다.
2. 같은 세션의 paper_role만 staff로 바꾼다.
3. 서버 등급과 키 조회 성공을 비교하고 동적 복구 키를 제출한다.

## 난도 근거

- 선언: 1 입문 (Intro).
- 브라우저에 준비된 편집기와 두 등급 이름, 요청·응답 설명이 있다. 한 값 변경으로 하나의 신뢰 경계를 관찰한다. 별도 도구 조작과 코드 읽기 없이 시작할 수 있어 입문으로 제안한다.
- 이 평가는 기술 재현과 작성자 검토에 근거한 초안이다. 독립적인 대상 수준 풀이자의 관찰로 재평가한다.

## 대안과 자료 노출 범위

개발자 도구로 실제 쿠키를 편집하거나 동일한 Cookie 헤더를 보내도 된다. 이 도구 조작은 일반 풀이의 필수 조건이 아니다. 기본 홈과 guest 응답에는 키가 없다. 서버 세션과 HttpOnly 식별자는 그대로 두고 역할 주장만 변경하는 것이 의도된 실험이다.

작성 기록과 풀이 스크립트는 작성자 자료이며 웹의 기본 본문·파일 도구는 선언한
플레이어 자료만 노출한다. 로컬 카탈로그 파일은 비밀 저장소로 취급하지 않는다.

## 기술 검증과 학습 리뷰

- 2026-10-02, Codex 작성·기술 검증. 최초 콘텐츠 구현 작업 트리 기준.
- 실제 HTTP에서 guest 거절, 세션 유지 후 staff 주장 성공, SID 없이 동일한 주장 성공을 확인했다. 패치는 유효한 서버 세션의 역할을 사용하며 guest·위조 SID·빈 쿠키를 거절한다. 단위 검사는 서버가 소유한 staff 세션의 정상 역할도 유지하는지 확인한다.
- `python3 -B tools/verify.py paper-session`: 고정 Python 3.13.15 이미지에서 풀이와 선언된 패치, 컨테이너·네트워크·볼륨 정리 통과.
- 작성자 내용 검토: 의뢰 맥락, 출발 정보, 완료 조건, 점진적 힌트와 해설의 보안 원리를 대조했다.
- Browser Plugin을 통한 실제 화면 조작 검증은 수행하지 않았다.
- 독립 학습 리뷰: 대상 수준 풀이자의 실제 리뷰는 아직 수행하지 않았다.
- 공개 준비: 기술 구현은 완료됐으며 독립 학습 리뷰와 난도 확인을 마친 뒤 공식 카탈로그로 공개한다.
