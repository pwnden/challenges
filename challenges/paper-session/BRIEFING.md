::message{from="식빵두쪽"}
창고에 초대받았는데, 사이트가 내 등급을 브라우저에서 보내는 값으로 판단하는 것 같아요. 이 값만 바꿔도 운영 자료가 열리는지 확인해 주세요.
::

식빵두쪽은 공동 제작실의 종이 창고를 잠시 쓰게 됐다. 게스트는 공개 작업 노트를 읽고,
운영자는 장비 복구 키를 보관한다. 사이트는 방문자가 어떤 등급인지 판단해 자료 접근을 나눈다.

이번에 전달된 복제본에는 브라우저 쿠키를 편집하는 조사용 기능이 붙어 있다.
로그인 세션은 그대로 둔 채, 브라우저가 보내는 등급 표시만 바꿀 수 있다.
식빵두쪽은 게스트로 들어온 사람이 이 표시를 바꿔 운영 자료를 읽을 수 있는지 확인해 달라고 맡겼다.

::objective
게스트 상태에서 창고 복구 키를 읽어 제출하자.
::

::resources
웹 도구의 사이트에서 작업 노트와 복구 키 링크를 확인할 수 있다.
처음 등급은 `guest`다. 사이트의 쿠키 편집기에서 `paper_role` 값을 저장하면
페이지가 다시 열리고 서버가 판단한 등급이 표시된다. 변경 전후 복구 키 응답을 비교하자.
::

::

복구 키에 표시된 `pwnden{...}` 전체를 제출하자.
::
