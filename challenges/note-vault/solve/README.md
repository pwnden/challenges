# 풀이와 패치

목록 조회는 로그인한 사용자 소유의 메모만 반환한다. 하지만 취약 버전의 개별 조회는 ID만 확인하고 메모의 소유자를 확인하지 않는다.

`guest`로 로그인해 `/notes/1`을 열고 주소의 ID를 `2`로 바꾸면 관리자 메모를 읽을 수 있다. API에서도 `/api/notes/2`에 같은 문제가 있다. `solve.py`는 게스트 세션을 얻은 뒤 이 API에서 현재 실행의 플래그를 회수한다.

`patched/policy.py`는 개별 조회에서도 `note["owner"] == user`를 확인한다. 소유하지 않은 메모는 존재하지 않는 메모와 같은 404를 반환한다. 목록을 숨기거나 ID를 복잡하게 만드는 대신, 읽기 요청마다 권한을 확인하는 패치다.

`patched/test.py`는 정상 로그인, 자신의 메모 목록·내용·HTML 조회, 잘못된 로그인, 로그인 전 조회, 타인의 메모 조회, 잘못된 ID를 검사한다. 풀이 성공 여부와 서비스의 정상 기능을 함께 확인한다.
