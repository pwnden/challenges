## 내 메모만 보이는 금고

개인 메모를 보관하는 작은 웹사이트에 접속했다. 게스트 계정에는 평범한 메모 하나만 보인다. 관리자의 복구 키도 같은 곳에 보관돼 있지만, 목록에서는 찾을 수 없다.

**목표는 게스트 계정으로 관리자의 메모를 읽고, 그 안의 복구 키를 찾아 제출하는 것이다.**

### 접속 정보

| 항목 | 값 |
| --- | --- |
| 아이디 | `guest` |
| 비밀번호 | `guest` |
| 제출 형식 | `pwnden{...}` |

### 여기서 시작하기

1. **문제 실행**을 누른 뒤 나타나는 **문제 열기**로 메모 사이트에 접속한다.
2. 위 계정으로 로그인하고, 메모 사이트를 살펴본다.
3. 원하는 메모를 찾아 복구 키를 복사하고, 이 작업 화면의 **플래그 제출**에 넣는다.

요청을 직접 만들어 보고 싶다면 오른쪽 터미널도 사용할 수 있다.

복구 키는 문제를 새로 실행할 때마다 바뀐다. 현재 열려 있는 문제에서 찾은 값을 제출하자.
