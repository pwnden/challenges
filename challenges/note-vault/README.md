개인 메모 사이트의 운영자가 길드에 확인을 맡겼다. 이 사이트에서는 로그인한 사람이
자기 메모를 목록에서 골라 읽는다. 각 메모는 작성한 계정의 개인 자료라서,
다른 계정으로 로그인한 사람에게는 내용이 공개되면 안 된다.

운영자는 관리자 계정 `admin`의 메모에 복구 키를 보관하고 있다. 평소에는 자기 목록에만
보이는 메모지만, 목록에서 숨겨져 있다는 것만으로 다른 사용자의 접근까지 막히는지
확인하고 싶어 한다. 이를 점검할 수 있도록 게스트 계정 `guest`를 전달했다.

게스트로 로그인하면 `Welcome`이라는 자기 메모 하나가 보인다. 네 조사는 이 메모를
여는 데서 시작한다. 메모를 읽는 기능이 계정별로 자료를 제대로 구분하는지 살펴보고,
같은 게스트 계정으로 관리자의 메모까지 읽을 수 있는지 확인해 보자.

## 의뢰 목표

게스트 계정으로 관리자의 메모를 읽고, 그 안의 복구 키를 찾아 제출하자.

## 접속 정보

| 항목 | 값 |
| --- | --- |
| 아이디 | `guest` |
| 비밀번호 | `guest` |

## 시작 전 알아둘 것

웹 도구에서 사이트를 열고 위 계정으로 로그인한 뒤, 목록의 `Welcome`을 눌러 보자.
메모마다 고유한 번호가 있고, 메모를 열면 주소에 그 번호가 표시된다.
목록에서 어떤 항목을 보여 주는지와 메모를 열 때 어떤 접근을 허용하는지 살펴보자.

복구 키는 `pwnden{...}` 형식이다.

복구 키는 실행 환경을 새로 준비할 때마다 바뀐다. 현재 메모 사이트에서 찾은 값을 제출하자.
