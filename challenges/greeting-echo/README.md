:person[문간지기]는 로비에 세운 안내 로봇 프로그램을 관리한다. 로봇은 두 기능을
제공한다. ECHO 기능은 요청한 바이트 수만큼 로봇의 내부 메모리를 그대로 돌려주는
점검용 기능이고, 화면에는 "0에서 64바이트까지"라고 적혀 있다. GREET 기능은
방문자 이름을 입력받아 인사말을 보여준다.

GREET 기능의 이름 입력은 선언한 크기보다 긴 값도 받을 수 있지만, 컴파일할 때
넣은 보호값이 그런 변조를 막아 준다고 알려져 있다. 문간지기는 최근 ECHO
기능과 그 보호값을 연결해 볼 수 있다는 이야기를 듣고, 실제로 관리자 전용
출력까지 끌어낼 수 있는지 확인이 필요해졌다.

플레이어에게는 로봇 프로그램의 실행 파일과 접속 주소가 주어진다. 실행 파일을
분석하거나 직접 접속해 두 기능을 시험할 수 있다. 조사 대상은 이름 입력만으로는
닿을 수 없는 관리자 전용 출력이다.

::objective
ECHO와 GREET 기능을 함께 사용해 관리자 전용 출력을 끌어내고, 그 안의 flag를 읽자.
::

::resources

- 대상 호스트: 문제 네트워크 안의 `app`, 포트 9200.
- 프로그램 파일: `files/kiosk` (실행 파일, 네트워크로 실행되는 것과 같은 프로그램).
- 프로토콜: 접속 후 ECHO 요청 줄(숫자 한 줄)을 보내면 로봇이 그만큼의 내부
  메모리를 돌려준다. 이어서 이름 입력을 보내면 인사말을 보여준다.
::
