::message{from="아직안잠"}
파일을 다른 장치와 맞춰 주는 프로그램을 설치했는데, 자꾸 이상하게 긴 사이트 이름을 조회해. 그 이름에 내 자료를 넣어 보낸 것 같아. 어떤 내용인지 확인해 줄래?
::

:person[아직안잠]은 여러 장치의 파일을 같은 상태로 맞춰 주는 동기화 프로그램을 사용했다.
이 프로그램은 서버에 연결하기 전에 도메인 이름에 해당하는 IP 주소를 묻는다.
이 과정을 **DNS 조회**라고 한다. 조회 기록에는 프로그램이 요청한 도메인 이름이 남는다.

기록을 보니 프로그램이 `sync.box.test` 앞에 긴 문자를 붙여 조회한 흔적이 있다.
아직안잠은 이 문자에 자료가 들어 있다고 의심해 분석을 맡겼다.
전달한 파일은 같은 동작을 로컬 실험에서 재현하면서 실제 요청과 응답을 기록한 자료다.
이름 맨 앞의 `1-`과 `2-`는 나눠 보낸 자료의 순서 번호다. 같은 요청을 다시 보낸 기록도 섞여 있다.

::objective
DNS 조회 이름에 나눠 담긴 두 문자 조각을 합쳐, 원래 내용을 찾아 제출하자.
::

::resources{title="전달받은 자료"}
`files/dns.jsonl`을 파일 도구에서 열어 보자. 한 줄이 요청 또는 응답 하나다.

- `direction`: Q는 프로그램이 보낸 조회 요청, R은 받은 응답이다.
- `id`: 요청과 응답을 짝지을 수 있는 번호다.
- `qname`: 프로그램이 조회한 사이트 이름이다.

`sync.box.test`로 보낸 조회 요청에서 번호 뒤의 두 문자 조각을 찾자.
번호 순서로 붙인 문자열을 아래 예제의 `문자열` 자리에 넣으면 복원할 수 있다.

```sh
printf '%s' '문자열' | base32 --decode
```

이 자료는 두 조각을 붙인 문자열을 그대로 명령에 넣으면 된다.
::
