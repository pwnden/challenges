# 시나리오 작성 기록

## 2026-10-02 설명 검토

프로그램이 사이트의 주소를 찾는 DNS 조회와 전달 기록의 필드를 먼저 설명한다.
번호 순서와 반복 요청을 읽는 행동으로 본문과 해설을 정리했다.
이번 검토는 작성자가 자료와 설명을 대조한 범위이며 독립 풀이자 리뷰는 대기 상태다.

## 시나리오와 학습 목표

아직안잠이 사용한 동기화 도구의 긴 조회 이름을 보고 분석을 의뢰한다. 대상을 조사하게 된 관찰을 일상적인 말로 설명한다.

- 대표 학습 분야: digital-forensics
- 세부 주제: forensics-network-evidence
- 계약 category: forensics
- 보안 학습 목표: 실제 DNS 교환 기록에서 데이터 조각을 골라 순서·재전송을 해석하고 질의 이름의 정보 전달을 설명한다.
- 대상 풀이자: 브라우저 사용과 텍스트 읽기를 할 수 있으며 제공된 조작을 수행하는 사람.
- 플레이어 도구: files, terminal. 현재 계약 선언으로 공통 플랫폼 도구를 소비한다.

풀이자가 필요한 설명을 문제 본문에서 읽는다. teaches는 위 보안 학습 목표이며,
구체적인 공격 식과 결과는 힌트·해설에 배치한다.
Python 문법 읽기나 코드 작성은 일반 풀이의 선수 능력에 포함하지 않는다.

## 의도된 풀이와 관찰

1. Q와 R을 구분하고 sync.box.test 질의를 고른다.
2. 1번·2번 조각을 번호 순서로 모으고 같은 재전송을 중복 계산하지 않는다.
3. 한 Base32 문자열로 복원해 전송값을 제출한다.

## 난도 근거

- 선언: 2 초급 (Easy).
- 필드 설명과 hello 변환 예제가 준비돼 있다. 여러 메시지의 선택, 조각 순서와 중복, 표현 변환을 연결하는 분석 부담으로 초급을 제안한다. 복잡한 프로토콜 파서나 코드 작성은 요구하지 않는다.
- 이 평가는 기술 재현과 작성자 검토에 근거한 초안이다. 독립적인 대상 수준 풀이자의 관찰로 재평가한다.

## 대안과 자료 노출 범위

공개 Base32 규칙을 지원하는 다른 도구도 같다. 자료는 가상 의뢰를 실제 루프백 UDP 서버·클라이언트로 재현한 기록이다. 실제 외부 침해의 캡처라고 주장하지 않는다. 응답 성공 여부를 질의 내용의 전송 조건으로 취급하지 않는다.

작성 기록과 풀이 스크립트는 작성자 자료이며 웹의 기본 본문·파일 도구는 선언한
플레이어 자료만 노출한다. 로컬 카탈로그 파일은 비밀 저장소로 취급하지 않는다.

## 기술 검증과 학습 리뷰

- 2026-10-02, Codex 작성·기술 검증. 최초 콘텐츠 구현 작업 트리 기준.
- authoring/capture.py가 실제 DNS wire 질의와 응답 열 개를 기록한다. 주소는 루프백이며 외부 DNS를 조회하지 않는다. 실제 base32 명령의 풀이가 제출 해시와 일치했다. 새 캡처와 배포 기록의 데이터 일치, 역순·중복·누락·충돌 검사 통과.
- `python3 -B tools/verify.py dns-detour`: 고정 Python 3.13.15 이미지에서 풀이와 선언된 패치, 컨테이너·네트워크·볼륨 정리 통과.
- 작성자 내용 검토: 의뢰 맥락, 출발 정보, 완료 조건, 점진적 힌트와 해설의 보안 원리를 대조했다.
- Browser Plugin을 통한 실제 화면 조작 검증은 수행하지 않았다.
- 독립 학습 리뷰: 대상 수준 풀이자의 실제 리뷰는 아직 수행하지 않았다.
- 공개 준비: 기술 구현은 완료됐으며 독립 학습 리뷰와 난도 확인을 마친 뒤 공식 카탈로그로 공개한다.
