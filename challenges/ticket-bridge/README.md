::message{from="핀보드"}
전시 모임 고객지원을 관리하는 핀보드입니다. 일반 회원이 자기 문의 목록에 없는 번호의 알림을 받았어요. 문의와 운영 초대를 함께 점검하고 싶은데, 회원 계정으로 운영 화면까지 열 수 있는지는 아직 확인하지 못했습니다. 같은 상황을 준비한 시험 사이트에서 확인해 주세요.
::

전시 모임 회원은 고객지원에 문의를 남기고 번호로 답변을 조회한다.
문의 본문은 작성자만 읽을 수 있어야 한다. 새 운영 담당자는 자기 계정에 발급된
초대 코드를 등록해 합류하며, 운영 담당자만 운영 화면의 접속 확인 코드를 볼 수 있어야 한다.

고객지원 관리자 :person[핀보드]는 잘못된 알림과 초대 기능이 계정 권한에 영향을
주는지 확인하려고 시험 사이트를 준비했다. 제공된 일반 회원 계정으로 문의 조회와
초대 등록을 조사할 수 있다. 계정·문의·초대는 모두 실습용이며 현재 브라우저의
시험 계정에서만 바뀐다.

::objective
일반 회원 계정으로 운영 화면을 열 수 있는지 확인하자.
운영 화면의 접속 확인 코드가 의뢰 완료 증거다.
::

::resources
- 웹 도구에서 전시 모임 고객지원을 연다. 별도 로그인 없이 일반 회원 `member`로 시작한다.
- 문의 목록, 번호 조회, 운영 초대 등록과 운영 화면을 사용할 수 있다.
- `처음부터 다시`는 회원 권한과 문의를 초기화하고 새 초대 코드를 만든다.
::

::submission
운영 화면에 나온 `pwnden{...}` 전체를 제출하자. 환경을 새로 준비하면 접속 확인 코드가 달라진다.
::
