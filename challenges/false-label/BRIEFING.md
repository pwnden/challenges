::message{from="잔비"}
예전 자료를 받았는데 이름이 banner.png로 붙어 있고 그림은 안 열려요. 안에 복구 자료가 있다고 들었는데, 어떤 파일인지부터 확인해 주세요.
::

잔비는 문을 닫은 동아리 사이트의 자료를 옮기고 있다. 전달 과정에서 파일 이름이 바뀌었고,
받은 파일에는 `.png` 확장자가 붙어 있다. 그림을 열어 보려는 시도는 실패했다.

이전 담당자는 여러 문서와 사이트의 복구 키를 압축 파일 하나에 넣었다고 알려 왔다.
복구 키는 사이트를 다시 사용할 때 필요한 비밀값이다. 잔비는 받은 파일을 그대로 전달했다.
파일이 어떤 형식인지 확인하고, 압축 파일 안에서 복구 키를 찾아 달라는 의뢰다.

::objective
banner.png의 실제 형식을 확인하고, 내부 복구 키를 찾아 제출하자.
::

::resources{title="전달받은 자료"}
받은 파일은 `files/banner.png`다. 파일 안에는 컴퓨터가 읽는 숫자 데이터인 **바이트**가 들어 있다.
터미널의 준비된 명령으로 앞부분의 숫자와 압축된 파일 목록을 확인할 수 있다.

앞 여덟 바이트를 16진수로 확인하는 명령은 다음과 같다.

```sh
od -An -tx1 -N8 files/banner.png
```

묶음 형식을 알아냈다면 아래 예제의 파일명을 전달 자료로 바꿔 목록을 읽자.
목록에 나온 내부 파일명은 그대로 복사해 쓸 수 있다.

```sh
tar -tzf 묶음파일
tar -xOzf 묶음파일 내부파일명
```
::
