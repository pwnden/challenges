# 시나리오 작성 기록

## 현재 설명 구성 (2026-10-04)

기본 브리핑에는 상황·목표·범위·접근 정보·자료 위치·제출 대상을 둔다.
풀이자는 자료를 읽고 사용할 도구와 비교 기준을 선택한다. 선택형 힌트가 막힌
판단을 돕고, 해설이 재현 명령과 결론을 설명한다. 공통 개념은 학습 연결에서
필요할 때 읽는다. 명령 예제를 기본 본문에 제공했던 기존 설계의 시작 정보·판단·
힌트 평가는 재검토 대기이며, 새 본문에 대한 심사를 완료했다고 간주하지 않는다.

이하 검토·설계 기록은 작성 당시 버전의 근거다. 본문의 명령 예제나 조작 설명을
언급하는 과거 기록은 현재 기본 브리핑의 제공 정보로 사용하지 않는다.

## 2026-10-02 설명 검토

전달 파일과 복구 키의 용도, 바이트의 뜻을 먼저 설명한 뒤 형식 확인 명령을 제공한다.
이번 검토는 작성자가 자료와 설명을 대조한 범위이며 독립 풀이자 리뷰는 대기 상태다.

## 시나리오와 학습 목표

잔비가 동아리 자료 이전 과정에서 이름이 달라진 파일을 받은 사람으로, 그림 열기 실패와 전달받은 설명을 함께 전한다.

- 대표 학습 분야: digital-forensics
- 세부 주제: forensics-files-metadata
- 계약 category: forensics
- 보안 학습 목표: 확장자 대신 식별 바이트와 실제 파서 결과로 파일 형식을 확인하고 내부 자료를 조사한다.
- 대상 풀이자: 브라우저 사용과 텍스트 읽기를 할 수 있으며 제공된 조작을 수행하는 사람.
- 플레이어 도구: files, terminal. 현재 계약 선언으로 공통 플랫폼 도구를 소비한다.

## 선수 능력과 개념 관계

- requires `file-signatures`: [공통 시작 지식](../../knowledge/file-signatures.md).

BRIEFING.md의 개념 참조는 공통 지식을 배포용 README.md에 반영한다.
풀이자가 필요한 설명을 문제 본문에서 읽는다. teaches는 위 보안 학습 목표이며,
구체적인 공격 식과 결과는 힌트·해설에 배치한다.
Python 문법 읽기나 코드 작성은 일반 풀이의 선수 능력에 포함하지 않는다.

## 의도된 풀이와 관찰

1. 준비된 od 명령으로 앞 여덟 바이트를 확인한다.
2. PNG와 gzip 표식을 비교하고 tar 목록으로 실제 구조를 확인한다.
3. 내부 목록의 복구 파일을 tar -xOzf로 화면에 읽는다.

## 난도 근거

- 선언: 1 입문 (Intro).
- 형식 표식과 필요한 명령을 문제 본문에서 제공한다. 도구 옵션을 발명하거나 분석 프로그램을 만들 필요가 없다. 파일 형식 식별이라는 한 개념과 자료 읽기의 짧은 경로라 입문으로 제안한다.
- 이 평가는 기술 재현과 작성자 검토에 근거한 초안이다. 독립적인 대상 수준 풀이자의 관찰로 재평가한다.

## 대안과 자료 노출 범위

gzip/tar 도구를 사용해 내려받은 자료를 조사해도 된다. 일반 경로는 추출 파일을 저장하지 않는 stdout 읽기다. 압축 자료는 이름만 PNG이며 정상 PNG를 주장하지 않는다. 압축을 비밀 보호로 설명하지 않는다.

작성 기록과 풀이 스크립트는 작성자 자료이며 웹의 기본 본문·파일 도구는 선언한
플레이어 자료만 노출한다. 로컬 카탈로그 파일은 비밀 저장소로 취급하지 않는다.

## 기술 검증과 학습 리뷰

- 2026-10-02, Codex 작성·기술 검증. 최초 콘텐츠 구현 작업 트리 기준.
- 실제 od·tar가 포함된 준비 이미지에서 자료를 읽고 제출 해시를 확인했다. authoring/build.py는 시간·사용자 메타데이터를 고정해 동일한 압축 자료를 생성한다. 회귀 검사가 배포 바이트와 생성 원본의 일치를 확인한다.
- `python3 -B tools/verify.py false-label`: 고정 Python 3.13.15 이미지에서 풀이와 선언된 패치, 컨테이너·네트워크·볼륨 정리 통과.
- 작성자 내용 검토: 의뢰 맥락, 출발 정보, 완료 조건, 점진적 힌트와 해설의 보안 원리를 대조했다.
- Browser Plugin을 통한 실제 화면 조작 검증은 수행하지 않았다.
- 독립 학습 리뷰: 대상 수준 풀이자의 실제 리뷰는 아직 수행하지 않았다.
- 공개 준비: 기술 구현은 완료됐으며 독립 학습 리뷰와 난도 확인을 마친 뒤 공식 카탈로그로 공개한다.
