:person[서가지기]는 안내소의 방문자 인사 단말기 프로그램을 관리한다. 단말기는
접속할 때마다 이름을 하나 입력받아 "환영합니다"로 응답하는 간단한 프로그램이다.

최근 누군가 아주 긴 이름을 입력했을 때, 알아볼 수 없는 몇 글자가 출력된 뒤
다시 이름 입력 안내로 돌아갔다는 제보가 들어왔다. 서가지기는 프로그램이
다시 시작된 것처럼 보였다고만 전하고, 그 글자들이 무엇이었는지나 왜 그런
일이 일어났는지는 알지 못한다.

플레이어에게는 단말기 프로그램의 실행 파일과 접속 주소가 주어진다. 실행
파일을 분석하거나 직접 접속해 긴 이름을 시험할 수 있다. 터미널에는 이
프로그램이 사용하는 것과 같은 공유 라이브러리도 이미 설치되어 있다.
조사 대상은 이름 입력만으로 단말기가 임의의 동작을 하게 만들 수 있는지다.

::objective
이름 입력만으로 단말기가 외부 명령을 실행하게 만들고, 그 결과로 나오는
flag를 읽자.
::

::resources

- 대상 호스트: 문제 네트워크 안의 `app`, 포트 9400.
- 프로그램 파일: `files/winlibc` (실행 파일, 네트워크로 실행되는 것과 같은 프로그램).
- 터미널에 이미 설치된 공유 라이브러리: `/lib/x86_64-linux-gnu/libc.so.6`
  (대상 서버가 사용하는 것과 동일한 파일이다).
- 프로토콜: 접속 후 이름을 보내면 "환영합니다"로 응답한다. 연결은 끊지 않는
  한 계속 유지된다.
::
