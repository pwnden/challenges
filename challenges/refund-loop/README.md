작업실 상점을 운영하는 톱밥입니다. 천 원만 넣어 둔 시험 계정으로 삼천 원짜리 한정판 상품을 샀다는 제보가 왔어요. 할인과 주문 취소 기능을 추가한 뒤에 생긴 일인데, 아직 어떤 조작으로 산 건지는 확인하지 못했습니다. 똑같이 준비한 시험 상점에서 실제로 구매할 수 있는지 확인해 주세요.

톱밥의 상점은 케이블과 한정판 키캡을 판매한다. 구매 계정의 잔액으로 결제하고,
발송 전 주문은 취소할 수 있다. 상점은 취소한 주문의 결제액을 잔액으로 돌려줘야 한다.
행사 조건과 상품 가격은 상점에서 확인할 수 있다.

톱밥은 제보를 재현하려고 초기 잔액이 1,000원인 시험 계정을 준비했다.
이번 조사에서는 이 계정의 구매·할인·취소 기능을 사용할 수 있다.
실제 돈이나 외부 결제는 사용하지 않는다. 구매 기록과 잔액은 현재 브라우저의
시험 계정에만 남는다.
