:person[빗장당번]은 유지보수 게이트를 관리한다. 게이트는 포트 7000에서
연결을 받으며, 그 전에 정해진 포트 세 개에 정해진 순서로 먼저 접속해야만
열린다고 설명한다. 빗장당번은 그 순서 자체는 운영 비밀로 두고 있으며, 순서를
안다고 주장하지도 않는다.

접속 기록에는 노크 포트 범위(7001–7003) 전체에 짧게 접속한 흔적 뒤에 게이트가
응답했다는 줄이 남아 있다. 빗장당번은 그 접속이 올바른 순서를 따랐는지는
알 수 없고, 직접 재현해 보지도 못했다고 말한다. 조사 대상은 게이트가 실제로
순서를 확인하는지이며, 올바른 순서가 무엇인지 알아내는 것은 목표가 아니다.

::objective
게이트가 정해진 순서로 접속해야만 열리는지 확인하고, 현재 실행의 flag를
읽자.
::

::resources

- 대상 호스트: 문제 네트워크 안의 `app`.
- 노크용 포트 범위: TCP 7001–7003. 접속 자체가 노크이며 별도로 보낼 데이터는
  없다.
- 게이트 주소: `app:7000`. 접속하면 현재 상태에 따라 한 줄짜리 응답을
  돌려주고 연결을 끊는다.
::

바뀐다.
::
