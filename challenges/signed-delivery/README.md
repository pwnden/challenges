::message{from="온전한서명"}
납품 문서 사본의 수량과 도착지가 서로 달라요. 따로 받은 공개키와 서명으로 발신자가 승인한 원문을 확인해 주세요.
::

온전한서명은 납품 문서를 받는 담당자다. 발신자는 한 문서의 내용을 승인하고
서명을 별도로 보냈다. 수신 과정에서 사본 세 개가 생겼고 일부 항목이 달라졌다.
이름이나 수정 시각만으로 승인된 사본을 고르면 다른 수량이나 도착지를 처리할 수 있다.

온전한서명은 발신자에게 확인한 검증용 공개키와 분리된 서명을 길드에 맡겼다.
이 실습에서 제공된 키는 신뢰한 경로로 전달된 발신자의 키다. 서명은 원문에
대한 것이며 사본 중 정확히 하나만 원문 바이트를 유지한다. 실습용 키와 문서는
이 문제를 위해 생성했으며 실제 업무용 개인키는 사용하지 않는다.

::objective
신뢰한 공개키로 각 사본을 검증해 승인된 원문을 고르고, 그 원문의 SHA-256을 확인하자.
::

::resources{title="문서와 검증 자료"}
- `files/copy-a.txt`, `files/copy-b.txt`, `files/copy-c.txt`는 내용이 다른 사본이다.
- `files/sender-public.pem`은 신뢰한 발신자의 공개키다.
- `files/delivery.sig`는 원문에 대한 RSA/SHA-256 분리 서명이다.
- `files/trust-note.txt`는 키 전달 경로와 서명 방식을 설명한다.

아래 명령을 각 사본에 적용해 결과를 비교하자. 사본을 편집하지 않고 검사한다.

```sh
openssl dgst -sha256 -verify files/sender-public.pem -signature files/delivery.sig files/copy-a.txt
```

검증을 통과한 파일에 `sha256sum 파일경로`를 실행한다. 출력의 첫 64자리 소문자
해시만 제출 형식 안에 넣는다. 파일명과 공백은 포함하지 않는다.
::

::knowledge

### 준비된 터미널 명령 사용하기

터미널에는 한 줄의 명령을 입력하고 Enter를 누르면 된다. `files/`로 시작하는
경로는 이 문제의 배포 파일을 가리킨다. 명령 예제의 파일명은 조사할 자료의 이름으로 바꿔 넣자.

`printf '%s' 'hello'`는 줄바꿈 없이 `hello`를 출력한다.
`|`는 왼쪽 출력물을 오른쪽 프로그램의 입력으로 전달한다.
예를 들어 `printf '%s' 'hello' | sha256sum`은 정확히 다섯 글자를 해시한다.
`hello` 뒤에 줄바꿈이 추가되면 해시도 달라진다.

파일을 읽는 명령과 결과를 확인하는 명령은 문제의 전달받은 자료에 제공한다.
Ctrl+C는 오래 실행되는 명령을 중단하고, 위쪽 화살표는 이전 명령을 다시 가져온다.

### 문서와 분리된 서명 확인하기

발신자는 개인키로 문서에 서명하고 수신자는 공개키로 검증한다. 개인키는
발신자가 보관한다. 공개키를 공격자가 바꿀 수 있다면 검증 결과를 발신자의
증거로 믿기 어려우므로, 먼저 누구의 키인지 신뢰할 경로로 확인해야 한다.

분리된 서명은 문서와 별도 파일로 전달된다. 이 문제는 신뢰한 공개키와
RSA/SHA-256 서명을 미리 제공한다. 암호 수학이나 키 생성은 필요하지 않다.

`openssl dgst -sha256 -verify 공개키.pem -signature 서명.sig 문서.txt`는
해당 문서 바이트의 서명을 검사한다. 통과하면 `Verified OK`, 내용이 다르면
`Verification failure`와 종료 코드 1을 낸다. 이름·크기·수정 시각 대신 각 사본의
실제 내용을 검사한다. 문서에 줄바꿈 하나를 추가해도 검증이 달라질 수 있다.

`sha256sum 문서.txt`는 파일의 정확한 바이트를 해시하고 뒤에 파일명을 출력한다.
해시는 내용을 식별하지만 발신자의 신원을 보장하지 않는다. 서명으로 원문을
확인한 뒤 제출할 식별값을 계산한다. 서명은 문서를 암호화하거나 숨기지 않는다.
::

::submission
검증된 원문의 해시를 `pwnden{64자리 소문자 SHA-256}` 형식으로 제출하자.
문서에 정답 문자열이 그대로 들어 있지는 않다.
::
