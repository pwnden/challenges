::message{from="흰돛"}
공개 배포 전에 운영 설정을 지웠어요. 그런데 예전 값은 아직 볼 수 있다는 말을 들었습니다. 제가 보낸 묶음에서 정말 읽히는지 확인해 줄래요?
::

흰돛은 동아리의 일정 관리 예제 프로젝트를 정리해 공개했다. 설정에 쓰던 팀 복구
키는 구성원을 다시 등록하는 내부 기능용 값이라 공개 배포에 들어가면 안 된다.
담당자는 운영 설정 파일을 지우고, 키를 직접 입력하는 공개 예제 파일로 바꿨다.

배포 묶음에는 수정 이력을 관리하는 Git 저장소도 포함됐다. 흰돛은 현재 파일에서
키가 사라진 것은 확인했지만 이력까지 조사하지는 못했다. 현재 상태와 과거 기록을
비교하고, 전달한 묶음이 내부 키를 포함하는지 확인해 달라는 의뢰다.
저장소는 이 실습을 위해 만든 여섯 커밋의 독립 자료다.

::objective
현재 설정과 과거 변경을 비교해, 배포 묶음에 남은 팀 복구 키를 찾자.
::

::resources{title="전달한 소스 묶음"}
- `files/source.tar.gz`: 현재 파일과 `.git` 기록을 포함한 압축 묶음.
- `files/release-note.txt`: 배포 담당자가 수행한 조치와 자료 출처.

아래 명령으로 별도 작업 폴더에 풀고 현재 설정과 이력을 확인할 수 있다.

```sh
mkdir -p work
tar -xzf files/source.tar.gz -C work
cd work/source
ls -a
cat config/example.env
git log --all --stat
```

이력에서 바뀐 파일을 찾고, 아래 시작 설명의 명령으로 그 시점 내용을 읽자.
::
