공개 배포 전에 운영 설정을 지웠어요. 그런데 예전 값은 아직 볼 수 있다는 말을 들었습니다. 제가 보낸 묶음에서 정말 읽히는지 확인해 줄래요?
::

:person[흰돛]은 동아리의 일정 관리 예제 프로젝트를 정리해 공개했다. 팀 복구 키는
구성원을 다시 등록할 때 쓰는 내부 비밀값이라 공개 파일에 넣으면 안 된다.
담당자는 운영 설정 파일을 지우고, 키를 직접 입력하는 공개 예제 파일로 바꿨다.

배포 묶음에는 수정 이력을 관리하는 Git 저장소도 들어 있다. 흰돛은 현재 파일에
키가 없는 것은 확인했지만 과거 이력까지 조사하지는 못했다. 현재 파일과 과거 기록을
비교해, 배포 묶음에서 내부 키를 찾아낼 수 있는지 확인해 달라고 의뢰했다.
설정 파일의 이름 변경과 키 교체도 있었다. 교체 전 키까지 같은 이력에 남을 수
있으므로 이번 배포에 쓰던 키를 구분해야 한다. 저장소는 여덟 커밋의 실습 자료다.

::objective
이번 배포 정보와 이름 변경·키 교체 이력을 연결해, 설정 삭제 직전의 팀 복구 키를 찾자.
::
