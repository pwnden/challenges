:person[야간당직]는 운영팀의 야간 진단 콘솔 프로그램을 관리한다. 콘솔은
접속할 때마다 명령 한 줄과 메모 한 번을 차례로 받는다. 명령으로는 STATUS만
의미 있는 응답을 돌려주고, 그 외에는 모두 "알 수 없는 명령입니다"로
처리된다.

프로그램 안에는 운영진 전용 기록(SHOW-ADMIN-LOG)을 보여주는 처리 경로도
있지만, 그 글자 수가 명령을 받는 칸보다 길어서 타이핑으로는 완전한 명령을
넣을 방법이 없다. 야간당직은 이 때문에 안전하다고 생각했는데, 메모 입력
쪽을 이용해 그 처리 경로를 간접적으로 실행시킬 수 있다는 이야기를 듣고
확인이 필요해졌다.

플레이어에게는 콘솔 프로그램의 실행 파일과 접속 주소가 주어진다. 실행
파일을 분석하거나 직접 접속해 두 입력을 시험할 수 있다. 조사 대상은 명령
입력으로는 닿을 수 없는 운영진 전용 기록이다.

::objective
메모 입력을 이용해 운영진 전용 기록(SHOW-ADMIN-LOG)을 끌어내고, 그 안의
flag를 읽자.
::

::resources

- 대상 호스트: 문제 네트워크 안의 `app`, 포트 9300.
- 프로그램 파일: `files/console` (실행 파일, 네트워크로 실행되는 것과 같은 프로그램).
- 프로토콜: 접속 후 명령 한 줄(`STATUS` 권장)을 보내면 응답과 다음 안내가
  온다. 이어서 메모를 보내면 저장 결과를 보여주고 연결을 닫는다.
::
