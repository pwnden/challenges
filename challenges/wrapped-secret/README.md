다른 사람도 복구 키를 내보낸 파일을 내려받을 수 있어요. 열면 이상한 글자만 나와서 괜찮을 줄 알았는데… 다른 사람도 원래 값을 읽을 수 있나요?

:person[moru17]은 장비 복구에 쓰는 비밀값인 복구 키를 파일로 내보내 보관했다.
내보내기는 장비 안의 값을 별도 파일로 저장하는 기능이다. 파일을 열자 알아보기
어려운 문자열이 나왔다. moru17은 다른 사람도 원래 복구 키를 읽지 못할 거라고 생각했다.

그런데 지금은 다른 사람도 그 파일을 내려받을 수 있다. moru17은 다른 사람도
이 파일에서 원래 복구 키를 읽어 낼 수 있는지 확인해 달라며 길드에 파일을 보냈다.

내보내기 안내에는 ‘텍스트를 Base64로 저장한다’고 적혀 있다.

네가 받은 `files/recovery.txt`에는 복구 키를 Base64로 바꿔 적은 값이 들어 있다.
이 값에서 원래 텍스트를 읽어 낼 수 있는지 직접 확인해 보자.

::objective

전달받은 자료를 원래 텍스트로 되돌려 복구 키를 확보하고 제출하자.
::

::resources

- 파일 도구의 `files/recovery.txt`에 내보낸 값이 들어 있다.
- 내보내기 방식은 Base64다.
- 준비된 터미널에는 값을 되돌리는 `base64` 명령이 있다.
::

::knowledge

Base64는 데이터를 정해진 문자들로 나타내는 방식이다.
예를 들어 `hello`를 Base64로 나타내면 `aGVsbG8=`가 된다.

터미널에서 다음 예를 실행하면 `hello`가 출력된다.

~~~sh
printf '%s' 'aGVsbG8=' | base64 --decode
~~~

`printf`는 문자를 내보내고, `|`는 그 출력을 다음 명령에 전달한다.
`base64 --decode`는 Base64 값을 원래 데이터로 되돌린다.
파일을 읽을 때는 `base64 --decode 파일경로` 형태로 입력한다.
터미널은 이번 의뢰의 자료가 있는 폴더에서 시작한다.
::
