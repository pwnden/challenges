**moru17**은 장비를 복구할 때 쓸 키를 파일로 내보내 보관해 두었다.
내보내기는 장비 안의 값을 별도 파일로 저장하는 기능이다. 만들어진 파일을 열어 보니
읽을 수 없는 문자처럼 보여, moru17은 복구 키가 보호된 상태라고 생각했다.

그런데 그 파일이 다른 사람도 받을 수 있는 곳에 공개됐다. 내보내기 안내에는
‘텍스트를 Base64로 저장한다’고 적혀 있었지만, moru17은 그 말이 비밀값을 안전하게
보관한다는 뜻인지 알지 못했다. 파일을 가진 사람이 실제 복구 키를 알아낼 수 있는지
확인해 달라며 길드에 같은 파일을 보냈다.

네가 받은 `files/recovery.txt`에는 내보내기로 바뀐 형태의 값이 들어 있다.
이 값에서 원래 텍스트를 읽어 낼 수 있는지 직접 확인해 보자.

## 의뢰 목표

전달받은 자료를 원래 텍스트로 되돌려 복구 키를 확보하고 제출하자.

## 전달받은 정보

- 파일 도구의 `files/recovery.txt`에 내보낸 값이 들어 있다.
- 내보내기 방식은 Base64다.
- 준비된 터미널에는 값을 되돌리는 `base64` 명령이 있다.

## 시작 전 알아둘 것

Base64는 데이터를 정해진 문자들로 나타내는 방식이다.
예를 들어 `hello`를 Base64로 나타내면 `aGVsbG8=`가 된다.

터미널에서 다음 예를 실행하면 `hello`가 출력된다.

~~~sh
printf '%s' 'aGVsbG8=' | base64 --decode
~~~

`printf`는 문자를 내보내고, `|`는 그 출력을 다음 명령에 전달한다.
`base64 --decode`는 Base64 값을 원래 데이터로 되돌린다.
파일을 읽을 때는 `base64 --decode 파일경로` 형태로 입력한다.
터미널은 이번 의뢰의 자료가 있는 디렉터리에서 시작한다.

복구 키는 `pwnden{...}` 형식이다.
