## 조사 결과

공개된 파일의 Base64 값을 되돌리자 복구 키가 그대로 나왔다.
값을 얻는 과정에 비밀 키가 필요하지 않았다.

## 조사 과정

1. 파일 도구에서 `files/recovery.txt`를 읽는다. 내보내기 안내의 Base64 표기를 확인한다.
2. 준비된 터미널에서 다음 명령을 실행한다.

   ~~~sh
   base64 --decode files/recovery.txt
   ~~~

3. 출력된 복구 키를 읽는다.

## 의뢰 완료 확인

제출할 값은 `pwnden{encoding_has_no_secret_key}`다.

## 드러난 보안 원리

표시 방식의 변환은 정보를 주고받기 편하게 만든다. Base64 규칙은 공개돼 있으며,
파일을 가진 사람은 같은 규칙으로 내용을 복원할 수 있다.

복구 키를 다른 사람이 읽지 못하게 하려면 파일 접근을 제한하고, 필요에 따라 비밀 키를 사용하는
암호화를 적용해야 한다. 내보내기 자료에 복구 키를 포함할 필요가 있는지도 검토해야 한다.
