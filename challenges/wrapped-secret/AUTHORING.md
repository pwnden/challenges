# 시나리오 작성 기록

## 2026-10-02 설명 검토

복구 키가 무엇에 쓰는 비밀값인지 설명하고 Base64로 바뀐 자료의 위치와 읽기를 맞췄다.
이번 검토는 작성자가 자료와 설명을 대조한 범위이며 독립 풀이자 리뷰는 대기 상태다.

## 시나리오 설정

- 한 줄 소개와 목소리: moru17이 장비 복구 키를 내보낸 파일의 공개 이후 원래 값이 노출되는지 확인해 달라고 맡긴다. 읽기 어려운 표시를 신뢰했던 사정을 존댓말로 밝힌다.
- 길드를 찾은 이유: 자료가 공개된 뒤 읽기 어려운 표기가 복구 키를 보호하는지 확신하지 못해 분석을 의뢰한다.
- 플레이어의 역할: 제공된 로컬 대상 또는 배포 자료를 조사하는 길드 조사자.
- 목표와 완료 증거: Base64로 표시된 복구 키를 준비된 명령으로 복원하고 공개 변환 규칙의 기밀성 한계를 설명한다.
- 공개 정보는 README.md, 단계별 발견은 hints/, 완전한 재현은 solve/README.md에 둔다.
- 등장인물은 이번 의뢰의 짧은 설정으로 사용한다. 별도 이야기 저장소의 구조는 후속 설계에서 정한다.

- category 근거: 위 학습 주제를 현재 계약의 가장 가까운 분류로 표시한다.

## 선수 지식과 학습 내용

시작 능력은 브라우저 사용과 텍스트 입력·읽기다. 이번 문제에서 필요한 추가 용어와
조작은 README.md의 전달받은 정보와 시작 전 알아둘 것에서 설명한다.
프로그래밍 언어 문법을 읽거나 코드를 작성하는 능력을 풀이의 선수 조건으로 두지 않는다.

## 난도 근거

- 선언한 값: 1 입문
- 전체 풀이 부담: 본문에 동작 예제와 파일 입력 문법을 제공한다. 하나의 공개 변환 규칙을 실제로 적용하며 코드 작성과 암호 수학이 없다. 초급 수준의 방식 추정이나 변환 조합도 요구하지 않는다.
- 구현 부담: 준비된 도구의 입력과 자료 관찰. 풀이 코드 구현은 요구하지 않는다.
- 등급은 아래의 독립 학습 리뷰 결과에 따라 재검토한다.

## 다른 풀이와 정답 노출

파일을 내려받아 동일한 Base64 디코딩 도구를 사용해도 된다. 풀이 스크립트는 플레이어와 같은 base64 실행 파일을 직접 사용한다. 배포 자료에는 인코딩된 값만 둔다.

풀이자에게 필요한 사전 설명은 기본 브리핑에 둔다. 로컬 카탈로그의 작성자 파일은
비밀 저장소로 취급하지 않으며, 사이트의 기본 파일 도구에는 배포 자료만 선언한다.

## 검증과 리뷰

- 실행 범위: 고정 텍스트 배포 자료와 실제 GNU base64 실행. 해시는 명령 출력의 정답을 검증한다. 서비스와 패치 실행은 필요 없다.
- 기술 확인 범위: 고정된 도구 이미지에서 본문 예제와 실제 디코딩 명령을 실행하고, 잘못된 데이터의 오류와 정답·오답 해시 판정을 확인한다.
- 기술 검증: 2026-10-02, 이 파일을 포함한 최초 콘텐츠 제출 버전. 호스트 Python 3.14.7, 풀이 이미지 Python 3.13.15, Docker 29.4.1, Compose 5.1.3에서 형식 검사, 전체 6개 문제 풀이·선언된 패치·정리 검사와 47개 회귀 검사를 통과했다.
- 격리 검증: 도달 가능한 대조군을 확인한 뒤 외부 IPv4·IPv6·DNS, 호스트와 별도 문제 네트워크 접근 차단, 같은 문제 내부 HTTP 성공 및 대조군 정리를 확인했다.
- 내용 검토: Codex가 초기 사용자 관점으로 배경·단계별 단서·해설·정답 노출을 검토했다. 독립 학습 리뷰와는 구분한다.
- 맥락 보완: 2026-10-02, Codex가 복구 키 내보내기·파일 공개·Base64 표시를 보호 수단으로 생각한 사정을 본문에 연결했다. 전달 파일과 디코딩 과정·정답 조건을 대조했다.
- 독립 학습 리뷰: 대상 수준 풀이자의 실제 리뷰는 아직 수행하지 않았다.
- 공개 준비 상태: 기술 검증과 별도로 독립 학습 리뷰와 난도 확인을 마친 뒤 공개한다.
