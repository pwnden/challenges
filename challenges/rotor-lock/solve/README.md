# 풀이

`encode`는 각 입력 바이트를 위치별 마스크와 앞선 출력 바이트로 XOR한 뒤 왼쪽으로 회전한다. 이 연산은 모두 역산할 수 있다.

1. `TARGET[i]`를 `i % 7 + 1`만큼 오른쪽으로 회전한다.
2. 위치별 마스크 `(0x53 + 13 * i) & 0xff`와 XOR한다.
3. 앞선 출력 바이트와 XOR한다. 첫 바이트에는 초기값 `0xa7`을 쓴다.

복원한 바이트를 UTF-8로 읽으면 `pwnden{rotate_then_xor_then_check}`가 나온다. `solve.py`는 배포 파일에서 검사값을 읽어 역산하고, 복원된 입력의 성공과 변조된 입력의 실패를 실제 검사기로 확인한다. 마지막에 플래그만 stdout으로 출력한다.
