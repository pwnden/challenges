## 잠금장치를 열어라

오래된 보관함의 잠금장치는 비밀번호를 그대로 저장하지 않는다. 입력을 여러 번 변형한 뒤, 미리 저장된 값과 비교한다. 관리자가 남긴 검사 코드를 확보했지만, 비밀번호는 사라졌다.

**목표는 검사기가 받아들이는 입력을 복원하는 것이다.** 그 입력이 곧 제출할 플래그다.

### 손에 쥔 단서

자료의 `checker.py`에는 입력을 변형하는 함수와 비교 대상인 `TARGET`이 들어 있다. 검사기는 입력이 맞으면 `unlocked`, 틀리면 `locked`를 출력한다.

암호를 무작정 대입하기보다 입력이 어떤 순서로 변하는지 읽어 보자. 각 위치의 계산에는 앞선 계산 결과도 쓰인다. 비트 연산이 낯설다면 힌트를 하나씩 열어 볼 수 있다.

### 여기서 시작하기

1. 아래 **자료 열기**로 검사 코드를 읽는다. 다운로드 없이 볼 수 있다.
2. 직접 계산하거나 코드를 실행하려면 오른쪽 **터미널 연결**을 누른다. 자료는 연결된 작업 공간에 준비돼 있다.
3. 복원한 문자열을 **플래그 제출**에 넣는다. 형식은 `pwnden{...}`다.

이 문제는 별도로 실행할 웹사이트가 없다. 자료 분석과 터미널만으로 풀 수 있다. 막히면 단계별 힌트를, 풀이를 마쳤거나 전체 과정을 보고 싶다면 해설을 열어 보자.
