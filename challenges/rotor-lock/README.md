오래된 보관함을 인수한 관리자가 길드에 잠금장치 분석을 맡겼다. 장치는 정상적으로
작동하지만, 이전에 사용하던 비밀번호가 남아 있지 않아 보관함을 열 수 없는 상황이다.
관리자는 입력한 비밀번호가 맞는지 판단하는 검사 코드 한 파일을 확보했다.

검사기는 입력한 글자를 숫자로 바꾸고 몇 가지 연산을 거친 결과를
저장된 숫자 목록과 비교한다. 원래 비밀번호는 코드에 적혀 있지 않지만,
**입력을 바꾸는 방법과 최종 비교값**은 함께 남아 있다.

관리자가 보낸 `files/checker.py`가 그 검사기다. 코드를 읽고 입력이 어떤 과정을 거쳐
비교값이 되는지 분석한 뒤 이 장치가 받아들이는 문자열을 복원해 보자.

::objective

검사기가 `unlocked`를 출력하는 입력 문자열을 찾아 제출하자.
그 문자열 전체가 `pwnden{...}` 형식의 플래그다.
::

::resources{title="전달받은 자료"}

- `files/checker.py`: 입력을 검사하는 코드. `encode` 함수는 입력을 변형하고,
  `TARGET`은 변형 결과와 비교하는 숫자 목록이다.
- 입력이 맞으면 `unlocked`, 틀리면 `locked`가 출력된다.
::

::knowledge

이 의뢰는 Python의 함수·반복문을 따라 읽는 능력과 바이트·비트 연산 지식이 필요한
코드 분석 문제다. 바이트는 컴퓨터가 데이터를 나타내는 단위이며, 한 바이트는 0부터 255까지의 값을 갖는다.
코드의 `^`는 XOR, `<<`와 `>>`는 비트 이동, `%`는 나머지 연산이다.
`0x`로 시작하는 숫자는 16진수이고, `& 0xFF`는 결과를 한 바이트 범위로 제한한다.
비트는 0 또는 1인 숫자 하나다. 한 바이트는 비트 8개로 이루어지며,
비트 회전은 한쪽 끝으로 밀려난 비트를 반대쪽 끝으로 옮기는 연산이다.

파일에서 `main`의 비교 부분을 먼저 찾고, 그 앞에서 호출하는 `encode`를 읽어 보자.
준비된 터미널에는 검사기를 실행할 Python이 있다. 입력을 시험할 때는 다음처럼 실행한다.

~~~sh
python3 files/checker.py 'pwnden{test}'
~~~

위 예시 입력에는 `locked`가 나온다. 복원한 문자열을 같은 위치에 넣어 실행했을 때
`unlocked`가 나오면 성공이다.
::
