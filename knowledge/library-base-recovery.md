# 유출된 주소로 계산하는 라이브러리의 실제 위치

프로그램이 사용하는 공유 라이브러리(예: C 표준 라이브러리)는 실행할 때마다
메모리의 다른 위치에 올라온다. 이 때문에 라이브러리 안의 함수 주소도 매
실행마다 달라진다. 하지만 라이브러리 파일 자체를 미리 가지고 있다면, 그
파일 안에서 각 함수가 "라이브러리 시작 지점으로부터 몇 바이트 떨어져
있는지"는 고정된 값이다.

실행 중인 프로그램에서 라이브러리 함수 하나의 실제 주소를 어떤 방법으로든
읽어내면(예: 그 함수를 호출할 때 쓰는 포인터 표를 그대로 출력시켜서),
그 값에서 라이브러리 파일의 해당 함수 오프셋을 빼면 그 실행에서 라이브러리가
실제로 올라온 시작 주소를 계산할 수 있다. 이 시작 주소에 다른 함수의
오프셋을 더하면 그 함수의 실제 주소도 알 수 있다. 오프셋은 `nm -D`나
`readelf`로 라이브러리 파일을 직접 읽어 확인한다.
