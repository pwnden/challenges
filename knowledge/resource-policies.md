# 동작과 리소스 권한

권한 정책은 **누가**, **어떤 동작을**, **어느 리소스에** 할 수 있는지를 정한다.
리소스는 문서, 보관소, 파일처럼 접근의 대상이다.

이번 로컬 실험의 정책에서 `Effect`가 `Allow`이면 접근 허용 규칙,
`Action`은 동작 이름, `Resource`는 대상 이름의 패턴이다.
예를 들어 `Action: "read"`, `Resource: "box/guest-*"`는 이름이
`box/guest-`로 시작하는 대상의 읽기를 허용한다. `*`는 뒤의 글자를 0개 이상 대신한다.

이 실험은 대소문자를 구분하며, 일치하는 허용 규칙이 없으면 거절한다.
명시적인 `Deny`가 일치하면 허용보다 우선한다. 사용자에게 표시한 별명보다
실제 요청의 리소스 이름과 규칙의 범위가 판단 기준이다.
이 규칙들은 제공된 로컬 평가기의 범위이며, 실제 클라우드는 조건과 정책 종류를 추가로 평가한다.
