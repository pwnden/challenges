# curl로 JSON API 읽기

API는 프로그램이 사용하는 요청 창구다. `curl -sS 주소`는 응답 본문을 읽고,
`-i`를 더하면 상태와 헤더도 보여 준다. JSON은 이름과 값으로 데이터를 표현한다.
예를 들어 `printf '%s' '{"note":{"id":3}}' | jq '.note.id'`는 숫자 3을 읽는다.

`curl -H 'Content-Type: application/json' -d '{"note_id":3}' 주소`는 JSON 본문을
보내는 POST 요청이다. `note_id`는 이 예제에서 작업 대상 문서의 ID를 뜻한다.
같은 문서를 읽는 GET 요청과 사본을 만드는 POST 요청은 서로 다른 작업이다.

로그인 응답의 쿠키를 저장하려면 `-c cookies.txt`, 이후 요청에 보내려면
`-b cookies.txt`를 사용한다. 쿠키는 서버가 로그인 상태를 이어서 확인하는 값이다.
JSON 본문을 바꿔도 로그인한 사용자와 서버가 보관한 문서 소유자가 바뀌지는 않는다.

상태만 확인할 때는 `-o reply.json -w '%{http_code}\n'`을 쓴다. 본문은 파일에
저장하고 상태는 화면에 표시한다. 200은 처리 성공, 401은 로그인 필요,
403은 권한 거부다. 상태와 실제 본문을 함께 비교하자.
