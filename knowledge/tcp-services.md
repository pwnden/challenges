# 포트와 TCP 연결

한 서버는 포트 번호별로 서로 다른 기능을 제공할 수 있다. HTTP 사이트를 여는
포트와 운영 점검 기능의 포트가 다를 수 있다. 포트가 열렸다는 것은 연결을
받는다는 뜻이며, 연결한 사람에게 모든 자료를 읽을 권한이 있다는 뜻은 아니다.

아래 `9000-9003`은 명령을 설명하기 위한 예시 범위다. 실제 조사에서는
브리핑에 적힌 호스트와 포트 범위로 바꿔 사용한다.

`nmap --unprivileged -sT -Pn -n -p 9000-9003 대상`은 정해진 네 포트에 일반 TCP
연결을 시도한다. `open`은 연결을 받음, `closed`는 연결 거부를 나타낸다.
이 문제에서는 제공된 호스트와 작은 범위만 사용한다.

HTTP 이외의 텍스트 프로토콜에는 `ncat`을 사용할 수 있다.
`printf 'HELP\n' | ncat -w 3 --idle-timeout 1 대상 포트`는 HELP와 줄바꿈을 보내고
응답을 읽는다. `\n`은 명령의 끝을 표시하는 줄바꿈이다. `-w`와 `--idle-timeout`은
연결·응답을 기다리는 시간을 제한한다. 안내와 오류를 읽은 뒤 해당 기능의
입력 형식을 사용한다. 오래 기다리는 명령은 Ctrl+C로 중단할 수 있다.

제공된 Ncat 7.95는 서버가 응답 후 연결을 닫아도 대기를 계속할 수 있다.
이 명령은 1초 동안 새 데이터가 없으면 `Idle timeout expired`를 표시하고 끝난다.
종료 코드 1만 보고 요청이 실패했다고 판단하지 말고, 받은 배너와 응답을 확인한다.
연결 거부·응답 누락은 정상 응답과 구분해야 한다.
