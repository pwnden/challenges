# 응답을 비교해 후보 줄이기

없는 주소가 안내 페이지로 연결되면 상태 코드가 200이어도 자료가 있다는 뜻은
아니다. `curl -sS 주소 -o body.json -w '%{http_code}\n'`은 본문을 파일에 저장하고
상태 코드를 출력한다. `wc -c < body.json`은 본문의 바이트 수를 센다.

같은 대상의 서로 다른 없는 주소가 동일한 안내를 주는지 먼저 비교한다.
`cmp first.json second.json`은 두 파일이 같으면 아무것도 출력하지 않고 끝난다.

`ffuf -w 후보파일 -u http://대상/FUZZ -fs 크기 -t 2 -rate 10 -maxtime 15`는
파일의 각 줄을 FUZZ 자리에 넣어 요청한다. `-fs`는 지정한 본문 크기를 제외한다.
`-t`는 동시에 요청할 작업 수, `-rate`는 초당 요청 수, `-maxtime`은 전체 시간
상한이다. 크기가 다른 응답은 조사할 후보이며 내용은 직접 확인해야 한다.

예를 들어 공개 도움말도 안내 페이지와 크기가 다르다. 후보가 나왔다고
비공개 자료가 유출됐다고 단정하지 말고, `curl`로 실제 본문을 읽어 공개 정책과
비교한다. `jq .`는 JSON을 읽기 좋게 표시한다.
