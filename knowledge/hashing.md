# 해시와 비밀번호 후보

해시 함수는 입력을 일정한 길이의 요약값으로 바꾼다. SHA-256의 결과는 보통
숫자와 `a`부터 `f`까지의 글자 64개로 표시한다. 같은 입력은 같은 결과를 만들며,
작은 변화도 보통 크게 다른 요약값을 만든다.

해시는 원문으로 되돌리는 변환을 제공하지 않는다. 대신 후보 원문을 직접 해시해서
알고 있는 요약값과 비교할 수 있다. 후보가 몇 개뿐이라면 전부 비교하는 데 큰 수고가 들지 않는다.

실제 비밀번호 저장에는 후보 대입 비용을 높이는 전용 비밀번호 해시 함수와
사용자별 salt가 필요하다. salt는 계정마다 달라지는 추가 값이다.
일반 해시를 한 번 적용한 값만 저장했을 때 어떤 확인이 가능한지 이번 실험에서 관찰한다.
