# 여러 연결에 걸친 순서 확인

한 연결 안에서 상태를 기억하는 것과, 서로 다른 연결 여러 개를 하나의 순서로
묶어 확인하는 것은 다른 문제다. "정해진 순서로 접속해야 한다"는 규칙을
구현할 때, 그 순서를 실제로 번호가 매겨진 단계로 확인하는지, 아니면 "그
단계들을 모두 거쳤는가"라는 집합으로만 확인하는지는 코드를 보기 전에는
같아 보인다.

집합으로 확인하면 순서는 더 이상 의미가 없다. 단계를 하나씩 차례로 거치지
않고 한꺼번에, 또는 거꾸로 거쳐도 같은 결과가 나온다. 이 규칙이 실제로
순서를 강제하는지 확인하려면, 안내된 순서를 따르지 않고 같은 단계들만
거쳐 보면 된다.
