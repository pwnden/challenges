# 주소의 경로와 입력값

`/view?file=welcome.txt`에서 `/view`는 서버의 기능을 가리키는 **경로**,
`?` 뒤의 `file=welcome.txt`는 그 기능에 전달하는 **입력값**이다.
`file`이 입력 이름이고 `welcome.txt`가 값이다.

값에 공백이나 `/` 같은 문자가 들어가면 브라우저가 다른 표기로 바꿔 전송할 수 있다.
`%2F`는 `/`의 URL 인코딩이다. 서버는 보통 이 표기를 풀어서 입력을 읽는다.
문제 사이트의 입력 폼은 이 전송 처리를 해 주므로, 폼에 원래 문자를 입력하면 된다.
