# Bundled fonts

## Pretendard Variable

Pretendard Variable 1.3.9 is bundled for local target pages. It is served by the
problem service, without external font requests.

Source: [upstream asset](https://github.com/orioncactus/pretendard/blob/5c41199ea0024a9e0b2cb31735265056e5472d76/packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2).
Revision: `5c41199ea0024a9e0b2cb31735265056e5472d76`.
License: [SIL Open Font License 1.1](Pretendard-OFL.txt).

## D2Coding

D2Coding Regular is bundled for code blocks and inline code in target pages.
It is served locally by the problem service, without external font requests.

Source: [upstream asset](https://github.com/naver/d2-coding-font/blob/9d6f0559691ebe670a23fbf7b72a8dc42362f1fb/site/fonts/D2Coding-Regular.woff2).
Revision: `9d6f0559691ebe670a23fbf7b72a8dc42362f1fb`.
License: [SIL Open Font License 1.1](D2Coding-OFL.txt).

Vite includes both font licenses in `assets/licenses` alongside the built fonts.
