# 파일 보기 화면 문구 갱신 검토

2026-10-14, Claude 작성자 검토. 범위: 파일 목록 탐색과 검색 화면의 문구.
`vulnerable/web/App.vue`가 첫 화면에서 `/`의 JSON 파일 목록을 읽는 동작과 대조했다. 실제 학습자 관찰은 포함하지 않는다.

| 문구 | 기준 | 대응 근거 | 판정 |
| --- | --- | --- | --- |
| 탐색 영역 “파일 목록”과 파일 이름 링크 | T1, T4 | 목록은 서버의 `/` 응답이 알려 주는 공개 파일 이름이며 링크는 `/view?file=` 주소와 같다. 현재 파일은 `aria-current`로 표시한다. | 충족 |
| 파일이 없을 때의 빈 상태 안내 | T3 | 목록 응답이 비었을 때만 보이며 서버가 숨긴 파일의 존재를 말하지 않는다. | 충족 |
